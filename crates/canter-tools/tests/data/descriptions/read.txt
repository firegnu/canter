Read a UTF-8 text file. Each returned line starts with its 1-based line number and ": " (for example "12: fn main() {"); that prefix is not part of the file. One call returns at most 2000 lines and 64 KiB; when more remains, the result ends with the startLine to continue from. Use startLine and lineCount to read part of a large file. Relative paths start from the session's working directory. Binary and non-UTF-8 files are rejected, and canter's state directory is always refused. Read a file before editing it, and when you need several files, read them in parallel in one reply.
