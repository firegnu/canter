Read a UTF-8 text file. Each returned line starts with its 1-based line number and ": " (for example "12: fn main() {"); that prefix is not part of the file. One call returns at most 2000 lines and 64 KiB; when more remains, the result ends with the startLine to continue from. Use startLine and lineCount to read part of a large file. Relative paths start from the session's working directory. JPEG, PNG, GIF and WebP images up to 8 MiB are attached for you to see; the user does not see them, so to show the user an image, open it in an image viewer. startLine and lineCount do not apply to images. PDF files up to 50 MiB are detected by content and converted to text with page markers; startLine and lineCount apply to that text. Pages needing OCR are listed without attaching images. Set page to a 1-based PDF page number to view any page as a PNG, including charts or scanned pages; this requires an image-capable model and local pdftoppm (brew install poppler). Text extraction does not require poppler. Each conversion has a 30 second timeout; page images obey the 8 MiB limit. Other binary and non-UTF-8 files are rejected, and canter's state directory is always refused. Read a file before editing it, and when you need several files, read them in parallel in one reply.
