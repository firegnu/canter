Run a command with /bin/sh -c in the session's working directory and environment. Each call starts a new shell, so cd, variables, and other shell state don't carry over to the next call. There is no terminal and no input: use non-interactive commands. Foreground timeout: 120 seconds by default, at most 600 (timeoutMs); output keeps its beginning and end. Set background=true for development servers, file watchers, or long tests: returns after about one second with an integer id, initial output and running/exited status. Background commands have no timeoutMs deadline and belong to the session, surviving client disconnects and session switches. Read new output with shell_output and stop the entire process group with shell_stop when finished. At most 8 background commands may run per session; each retains the last 1 MiB of output. The user can also move a running foreground command to the background with Ctrl+B. When a shell exits, its remaining process group is stopped. Results include exit status, so never add commands to print it. Background execution follows the same approval and Plan-mode read-only rules as foreground execution.
