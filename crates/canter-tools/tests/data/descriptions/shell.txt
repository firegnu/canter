Run a command with /bin/sh -c in the session's working directory and environment. Each call starts a new shell, so cd, variables, and other shell state don't carry over to the next call. There is no terminal and no input: interactive programs such as editors, pagers, prompts, or git rebase -i will wait until the timeout, so use non-interactive forms (for example git --no-pager log, git commit -m). Timeout: 120 seconds by default, at most 600 (timeoutMs). Standard output and error are combined, and long output keeps only its beginning and end. The result ends with the exit code, which the user also sees, so never add commands to print it. When the command finishes, background processes it started are stopped, so servers and watchers don't keep running. Read-only commands such as listing, searching, viewing files, and git status, log, or diff usually run without approval; other commands may wait for the user to approve them.
