# canter-tui

canter 的终端客户端：对话、批准框、会话列表、断线重连。下面只写输入框里的补全。

## 输入框

Enter 发送，Shift+Enter 或 Ctrl+J 换行，Ctrl+V 贴图片。输入框上方一次只开一个列表：
选择框（比如单打 `/mode`）、`/` 命令列表、`@` 文件列表，三者不会同时开。

## `/` 命令列表

第一个词以 `/` 开头、还没打空格时，列出名字以所打内容开头的命令。↑↓ 选，Tab 补全；
Enter 在命令名没打完时只补全、不执行，打完整了才执行。Esc 只关列表。

## `@` 引用文件

- `@` 在输入开头或空白后面、光标在这个 `@` 词里时，弹出会话目录（信息行里显示的那个目录，
  一般就是开 canter 时终端的当前目录）下的文件和目录，相对路径显示，目录以 `/` 结尾。
  `/btw` 等命令后面的文字里也能用。光标离开这个词、删掉 `@`、按 Esc，列表关掉；Esc 不清输入。
- 照 `.gitignore`、`.git/info/exclude` 和全局 gitignore 过滤（只在 git 仓库里生效，
  上层目录的 `.gitignore` 也算）；不在 git 仓库里时不按这些过滤。`.git`、`.hg`、`.svn`、`.jj`
  从不列出。隐藏文件照列。不跟符号链接进目录。
- 遍历在后台做，界面不等它。一次最多取 **10000** 个文件和目录（按名字顺序深度优先），超了不再往下找，
  列表底部写一行 `Only the first 10000 files and directories are listed`。
  每次新出现 `@` 词时重新遍历。列表最多占 10 行。
- 筛选：`@` 后面打的字按顺序出现在路径里就算中，不分大小写。排序依次看：
  1. 全部落在文件名（最后一段）里的排前面；
  2. 落成的连续段越少越前；
  3. 文件名以所打的字开头的排前面；
  4. 路径短的排前面，再按路径字母序。
- ↑↓ 选，Tab 或 Enter 把整个 `@` 词换成 `@相对路径` 加一个空格；选的是目录时换成 `@目录/`、
  不加空格，列表接着列这个目录里的东西（目录本身不再列出）。列表开着时 Enter 只补全、不发送。
- 路径里有空白时加双引号：`@"my notes.txt" `；目录是 `@"my dir/"`，光标停在右引号前，
  可以接着往下选。`@"` 开头的词到右引号为止（没有右引号就到行尾）。名字含 `"`、控制字符或
  不是 UTF-8 的文件不列出。
- 发出去的就是这段文字：不读文件、不把内容放进消息，模型要看内容自己用 `read` 工具读。
