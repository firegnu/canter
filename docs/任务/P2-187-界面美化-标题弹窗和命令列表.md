## 要做的

下面「现在」是主控 11-03 用装着的 `c5b7faf` 在 110 列终端里看到的样子。

### 1. markdown 标题分不出层级（原第 8 处）

- 现在：`#` 是加粗加下划线；`##`、`###` 都只是加粗，和正文里的 `**加粗**` 一模一样（`crates/canter-tui/src/markdown.rs` 的 `Tag::Heading`）。
- 要的：`##` 和正文加粗分得开，`###` 及以下和 `##` 分得开。可以参考 Codex 终端的做法（只参考、不搬代码）；颜色用 `theme.rs` 里现有的，深色、浅色终端都要看得清。
- 表格、代码块、列表、引用不变。

### 2. 信任文件夹对话框（原第 10 处）

- 现在（`crates/canter-tui/src/run_trust.rs`）：框里的字贴着左边框，没有留白；长路径在单词中间硬折行（`…/55677df5-b7be` 换行 `-47c6-…`）；选项下面空着好几行。
- 要的：
  - 框里左右各留一格。
  - 路径用 `~` 缩写；太长时在 `/` 处折行，或者中间省略，不在单词中间断开。
  - 框的高度跟着内容走，不留多余空行。
- 文字、选项、按键、判断逻辑都不变。

### 3. `/usage` 写进对话、数字没单位（原第 11 处）

- 现在：`/usage` 的表直接写进对话，留在那里；没有标题；数字是 `340000` 这样的原始数。`/context`、`/diff`、`/files` 是弹窗、按 Esc 关，数字写 `24k`。
- 要的：
  - `/usage` 改成和 `/context` 一样的弹窗，按 Esc 关，不留在对话里。
  - 第一行标题照下面第 4 节的统一写法，比如 `Usage`。
  - token 数用 `/context` 一样的写法（`app.rs` 的 `tokens()`：`340k`、`1.2M`）；金额不变。
- 表里的列和内容不变。

### 4. 弹窗标题写法不统一（原第 12 处）

- 现在：`/context` 第一行 `Context  ctx 19% …`；`/theme` 是 ` Theme · code and diff colours`；`/statusline` 是 ` Configure status line`，按键说明在下一行；`/model` 是 ` Model  ↑↓ select · Enter choose · Esc cancel`（标题和按键在同一行）；`/diff`、`/files` 是 `Diff`、`Files  read 2 · …`，按键说明 `Esc close` 在最后一行。提问框边框上的标题叫 `Ask user`（`question.rs`），从用户角度看不对。
- 要的：
  - 终端里所有输入框上方的弹窗、选择列表（`/` 能打开的那些：`/context`、`/diff`、`/files`、`/help`、`/model`、`/think`、`/theme`、`/statusline`、`/usage`、`/mode`、`/permissions`、`/mcp`、`/lsp`、`/memory`、`/skills`、`/ps`、`/agents`、`/resume`、`/rewind`、`/sandbox` 等，以代码里实际有的为准）用同一种写法：第一行加粗标题，后面可以跟 ` · ` 加暗色的简短说明；按键说明统一放最后一行，暗色。
  - 提问框标题改成 `Question`。
  - 批准框（`Edit this file?`、`Run this command?` 这类）的写法已经统一，不改。
- 只改标题和按键说明的位置、样式，不改列表内容和按键本身。

### 5. `/` 命令列表顺序（原第 13 处）

- 现在（`crates/canter-tui/src/commands.rs`）：前一半按字母（`/compact` … `/new`），后面 `/fork`、`/clear`、`/permissions`、`/plan`、`/resume` … `/goal` 是乱的。
