规则：

1. **第一行**（紧挨输入框）：左边是模型（服务商前缀 `opencode-go/` 灰色）、思考档位（只写档位，比如 `high`，灰色，不写 `think`）、权限模式和沙箱；右边靠右是上下文条和百分比、`cache` 总命中率、花费。
2. **第二行**：路径、分支（绿色，不加括号）、改动数 `+250 −6`（加绿减红，不加括号和逗号，没有改动时不显示）。路径能占多宽只由窗口宽度和分支名决定；改动数放不下时它自己不显示，不反过来挤路径。
3. **数字不推动别的东西**：右边的百分比固定 4 列宽、右对齐（` 58%`、`100%`）；数字变了，左边和路径都不动。
4. **只给要注意的上色**：`Allow all`、`Sandbox off` 红色；上下文条照现在按剩余多少分绿、黄、红；其余默认色或灰色。权限正常时（`Ask for execution`、`Always ask`、`Sandbox on`）灰色。计划模式照现在的 `Plan (then …)` 写法和颜色。
5. **去掉的**：版本号和提交、每次请求的缓存命中 `(last …%)`、上下文后面的 `232k/400k (… to compact)` 字样（只留条和百分比）。会话名和版本号默认不显示；在 `/statusline` 里打开的，灰色放在第二行靠右。
6. **速度**挪到干活那一行，取整数，宽度固定（右对齐 3 位，超过 999 照实写），只在模型出字时出现；`/statusline` 里的速度项管它显示不显示。
7. **活动行**：子 agent、后台命令、目标各一行，在两行信息下面，有才出现。子 agent 行和后台命令行的文字、↓ 选中、Enter 展开照 P2-240 现在的做法，提示放在行的右边、灰色（`↓ view`，选中时 `Enter open`）。目标行写 `◎ goal $0.12 / $5.00`（不是进行中时照 `goal::bar` 现在的写法带上状态，没有预算写 `unlimited`），不能选中；目标不再插在第一行最前面。
8. **窗口窄时**：第一行从右往左整项去掉，先去 `cache`，再去花费，再去上下文；左边的权限模式和沙箱照现在的规矩（沙箱要么完整显示要么不显示，`mode_in_full` 和 Shift+Tab 提示照旧）。第二行照现在的办法从中间缩路径。任何一项都不出现被切掉一半的样子。
9. **`/statusline`**：仍能选每一项显示不显示；顺序和换行位置不再由用户排，位置照上面固定。用户以前存的 `statusLine.items` 顺序和换行忽略，显示不显示照旧读。`useScript` 和状态栏脚本的行为不变（脚本打开时它的两行顶替这两行信息，活动行照旧在下面）。
