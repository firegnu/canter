## 要做的

- 在输入框里，`@` 出现在开头或空白后面时，弹出文件列表；接着打的字用来筛（不分大小写，路径里按顺序出现这些字就算中，越靠近文件名、越连续的排越前）。光标离开这个 `@` 词、删掉 `@`、按 Esc，列表关掉。
- 列表里是终端当前目录下的文件和目录，相对路径显示：照 `.gitignore`、`.git/info/exclude` 和全局 gitignore 过滤，不进 `.git`；不在 git 仓库里也能用（那时只跳过 `.git` 这类目录）。目录很大时不能卡住界面：遍历在后台做，有个数上限（你定，写进 README），超了只列前面的、列表底部说一句。
- ↑↓ 选，Tab 或 Enter 把选中的替换成 `@相对路径`（后面补一个空格；选的是目录就补 `/`、不补空格，可以接着往下选）。列表开着时 Enter 只补全、不发送。
- 发出去的消息里就是这段文字，不读文件、不改协议。路径里有空格等特殊字符时怎么写（比如加引号），你定，写进 README。
- `/` 命令列表和 `@` 列表不会同时开；`/btw` 等命令后面的文字里也能用 `@`。
- 依赖：可以加 `ignore`（ripgrep 的目录遍历库）做照 gitignore 过滤的遍历，版本核实后钉死；筛选和排序自己写。除此之外还要加别的依赖，停下来问。
