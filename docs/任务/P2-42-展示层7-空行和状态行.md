## 要做的

照方案第 7 项推荐和线框做，要点：

- **空行**：每个项目（一段话、一张卡片、一行思考）之间空一行；连着的读文件之间不空。用户消息前后本来就有空行，不变，也不叠成两行空行。已说完的部分和进行中的部分接起来的地方同样照这条，不因为一项从「进行中」变成「已说完」而多出或少掉空行。
- **状态行**：转圈后面的词按这一轮正在进行的那一项换，后面统一 `· 秒数 · Esc to interrupt`：
  - 思考 `Thinking`，写回答 `Writing`，shell `Running <命令第一行>`（放不下截断），读文件 `Reading`，改文件 `Editing`，MCP `Calling`，网页抓取 `Fetching`；
  - 没有正在进行的项目（比如等模型开口）照旧 `Working`；
  - 等批准、等回答、重连、中断中、出错、会话已关照旧，等批准、等回答不加 `Esc to interrupt`；
  - 和 P2-40 的 `Details shown · Ctrl+O to fold` 同时出现时两样都在，窄窗口先截哪个你定，写进完成记录。
- **卡片里不加转圈和计时**：只改状态行。状态行换词不能让往上翻时的 `↓ New output below` 误报（P2-16 定的：只有状态行的变化不算新输出）。
- README 里写空行规则和状态行的词。
