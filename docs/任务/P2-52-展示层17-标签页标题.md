## 要做的

标题（OSC 0，所有终端都写）：

| 状态 | 标题 |
| - | - |
| 在干活（模型在想、在答、在跑工具） | `⠋ canter · <目录名>`，符号照状态行的 `SPINNER` 转，最快每 100 毫秒换一格 |
| 等批准、等回答（批准框、提问框开着） | `✋ canter · <目录名>` |
| 这一轮做完 | `✓ canter · <目录名>` |
| 这一轮出错 | `✗ canter · <目录名>` |
| 空闲 | `canter · <目录名>` |

- `<目录名>` 是会话工作目录的最后一段；是家目录本身时写 `~`。
- `✓`、`✗` 留着，直到在这个 canter 里按任意键才回到空闲；用户按 Esc 打断的这一轮直接回空闲，不显示 `✗`。
- 只在标题文字变了时才写。标题去掉控制字符和双向、不可见字符，太长截断（照 Codex 的清洗）。
- 启动时的会话列表（`--resume`）和 `/resume` 列表开着时写空闲的样子。
- 退出时（正常退出、Ctrl+C / Ctrl+D、SIGHUP、SIGTERM）写一个空标题，让终端用回自己的默认标题；不去读、不去恢复原来的标题。

标签上的忙 / 等待（OSC 9;4，只发给确认支持的终端）：

- 只在 Ghostty 和 iTerm2 3.6 及以上发，按 `TERM_PROGRAM`（和 iTerm2 的 `TERM_PROGRAM_VERSION`）判断。这两个版本是主控凭记忆写的，先用它们的发布说明或源码核实：哪个版本开始认 `OSC 9;4`、各个值是什么意思；核实不了，或者和这里写的不一样，停下来问。
