## 重点看

1. **认证是第一关**：TCP 上所有请求（含未知路径、错误方法、SSE、带请求体的、升级类请求）是否都先过 `authenticate`，失败时没有任何处理（不建会话、不发事件、不读请求体）；unix socket 那一路是否确实没套认证、行为和改之前一样（`remote.rs` 的 `router`、`lib.rs` 里两个 `axum::serve`）。
2. **令牌**：生成的随机性和长度、只存 sha256、常量时间比较、文件权限和原子写入、并发 add/remove；令牌和请求头不进日志、错误、doctor（`remote_tokens.rs`、`authenticate`）。
3. **撤销**：删掉令牌后新请求立刻 401，已开的 SSE 流断开；令牌文件坏了、读不了时全部拒绝；`refresh` 里按名字和摘要保留旧项的逻辑会不会让撤掉的令牌继续有效，或误断别人的流。
4. **换进程和启动**：`serve --replace` 时旧进程关 TCP、交锁、新进程绑端口的顺序有没有端口冲突或空窗里漏认证；关 TCP 时等长连接的 5 秒超时会不会拖住或卡住换进程；`remote.listen` 写错、端口被占时 unix socket 和服务端是否照常起来。
5. **只开回环**：`remote.listen` 的校验能不能放进非回环地址（IPv4 映射的 IPv6、`0.0.0.0` 之类），读代码判断，不要构造输入去试。
