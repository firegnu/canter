## 要做的

按键（只在主输入框；命令列表、@ 列表、批准框、提问框、各弹框开着时照它们现在的规矩先拿键，不变）：

| 按键 | 作用 |
| - | - |
| Alt+← / Alt+→，也认 Ctrl+← / Ctrl+→、Alt+B / Alt+F | 光标往前 / 往后跳一个词 |
| Alt+Backspace、Ctrl+W | 删掉光标前一个词 |
| Alt+Delete、Alt+D | 删掉光标后一个词 |
| Ctrl+A / Ctrl+E | 到本行行首 / 行尾（和 Home / End 一样） |
| Ctrl+K | 删到本行行尾；光标已在行尾时删掉这个换行（和下一行接上） |
| Ctrl+U | 删到本行行首；光标已在行首时删掉前面那个换行（和上一行接上） |

- 「行」按换行分（Enter 加 Shift、Ctrl+J 打出来的），不按窗口宽度自动折出来的行。
- 「词」：连着的字母、数字、下划线算一个词；中文连着的一串算一个词；中文和英文 / 数字交界、标点、空格、换行都是分界。往前删一个词：先跳过光标前面的分界字符，再删掉前面那个词；往后同理。往前跳、往后跳和删的范围一致。例子（光标在末尾，Alt+Backspace 连按）：
  - `把 src/app.rs里的问候语改一下` → `把 src/app.rs` → `把 src/app.` → `把 src/` → `把 ` → 空
- 图片标记 `[Image #N 名字]` 整个算一个词：按词删时整个删掉、对应的附件跟着去掉，跳的时候一步跳过；不会删出半截标记。
- Ctrl+C 有字时清空整段草稿，照旧不变。
- 原来这些组合键在输入框里什么都不做（不插字），不会和现有功能冲突；有冲突的（比如某个组合已经有用处）停下来问。
