## 要做的

- **打开和关闭**：Ctrl+F 打开搜索，输入框换成 `Find: <关键词>`，原来的草稿留着，关掉后原样回来。批准框、提问框开着时 Ctrl+F 不打开搜索。
- **边打边搜**：每改一次关键词就重新搜，从最新的往前找，跳到离底部最近的一处，把它滚到看得见的地方。关键词为空时不高亮、不跳。
- **高亮**：当前这一处反白，屏幕上其它匹配加下划线。和 P2-45 的选区不打架：打开搜索时清掉选区。
- **计数和提示**：状态行写 `Find · 2/7 · ↑ older · ↓ newer · Enter stay · Esc back`；找不到时写 `No matches`，如果 Ctrl+O 收着，后面加 `· Ctrl+O to search folded parts`。窄窗口怎么截你定，写进完成记录。
- **按键**：
  - ↑ 或 Ctrl+P 跳到更早的一处，↓ 或 Ctrl+N 跳到更新的一处，到头了停住，不绕圈；
  - Enter 关掉搜索，停在这处匹配上接着看；
  - Esc 关掉搜索，回到打开搜索前看的位置（原来在跟着最新输出就回到最底下）；
  - 其它编辑键照输入框的规矩改关键词。
- **搜哪些**：画面上显示的文字：你的消息、回答、思考那一行、工具卡片、提示行。折起来的部分（思考全文、长输出中间省略的、长 diff）不搜；按 Ctrl+O 展开后就能搜到。不分大小写。跨显示行的匹配（窗口窄折开的一个词）你定要不要算，写进完成记录。
- **对话在变**：搜索开着时模型还在输出，新内容里的匹配算进总数，画面不被拉回最底下；当前这一处钉在内容上，不因为新内容错位（照 P2-45 选区的办法）。改窗口宽度、按 Ctrl+O 时按新的画面重新搜，尽量留在原来那一处附近。
- README 加「对话里搜索」一节；`/help` 里有快捷键说明的地方加上 Ctrl+F。

**拿主意的地方**

- 计数从最早的往后数：`2/7` 是从最早数的第 2 处，打开后先停在最新的 `7/7`。这样对话往下长时当前那处的编号不变、只有总数变，也和浏览器、编辑器的习惯一样。（示意里的 `2/7` 照哪种数法都对不上那张图，不影响。）
- 跨行的匹配不算：一处匹配只在一行里。按画面上的行整行搜，高亮正好落在画出来的格子上；要算跨行得把折行接回再映射回格子，而且只能搜正文。代价：窗口窄、一句话被折到两行时，跨行那处搜不到。
- 整行都搜，包括卡片右边的状态（`exit 1`、`declined`）和 `… N more lines · Ctrl+O` 这类提示行，不只搜复制时取的正文。
- 窄窗口：状态行从后往前去掉按键提示（先去 `Esc back`，最后去 `↑ older`），`Find · 2/7` 留着；还放不下行尾直接截掉。0 处时先去 Ctrl+O 那句。
- 还没打字时状态行写 `Find · Esc back`。
- Ctrl+C：有关键词时清空（照输入框的规矩），已经空了再按同 Esc（输入框空着时 Ctrl+C 是退出，搜索里不退出）。Ctrl+J、Shift+Enter 不换行，Ctrl+V 不贴图；粘贴进关键词，换行变空格。
- 搜索开着时批准框、提问框弹出来：搜索关掉、停在当时的位置（同 Enter），按键交给批准框。选择框（比如 `/mode`）开着时按键先给选择框，Ctrl+F 在选择框开着时不打开。
- 跳到的那处不在画面里时滚到画面中间；在画面里就不动。
- 搜索开着、有当前一处时，画面不跟着最新输出走（和按住鼠标时一样），下面有新内容照旧出 `↓ New output below`。
- 当前一处的钉法：哪一项、项里哪一行（用 P2-45 选区的 `Key`：命令输出按原输出的行号，折出来的行算上一行）、这行里第几处。找不到了（那段字不再显示）换到同一项里离得最近的一处，没有就按行最近的；改宽度、Ctrl+O 后先按钉法找，找不到同样换最近的，然后滚到看得见。
- 已说完的部分的匹配记在 `History` 里，每个已说完的项对同一个关键词只搜一次；进行中的部分每帧重搜。每行先整行转小写看有没有，有才逐个字素对。
