## 怎么做

1. 用户在场，同意开始。
2. 用户自己把 DeepSeek 的 API key 配进 canter 的配置（照 P1-5 定的位置）；主控不经手 key，不把 key 写进任何文件、日志、提交。
3. 装法照 `CLAUDE.md`「安装和部署」：切换用户 PATH 上的程序、起用户真实状态目录下的服务端，都在用户在场时做；装之前先和用户定装到哪、怎么退回，写进 DESIGN 和 HANDOFF。
4. 用户挑一件小活（在一个真实仓库里），canter 干一遍；需要的话 pi 用同样的话再干一遍，对比。
5. 顺带确认 P1-2 审查留下的两处：思考开关切换以后带工具接着聊会不会被拒；上下文超长时 DeepSeek 的报错原文，canter 能不能认出来。
6. 记录：DeepSeek 调了几次（看服务端的用量记录），哪里不如 pi，哪里出了错。

## 怎么算做完

- 「初步能达到pi我就很满意了」：用户判断。

## 不要做

- 用户不在场时不真调 DeepSeek。
- 不动用户的其他 agent，不用 ChatGPT 订阅。
