# 任务：第二期-13.5 - 后台命令的状态改成英文

2026-11-02，主控建。
依据：终端里后台命令的状态写成了中文「后台运行中」，界面应该都是英文。本件只把这几个字换成英文，不改别的。
执行：派出
优先：低

## 用户原话

- 11-02 讨论 P2-179 时主控看到 `crates/canter-tui/src/background.rs` 里的「后台运行中」，问要不要记下。用户：「都按你的建议，记进HANDOFF」。
- 主控建议不并进 P2-179、以后单独改。用户：「分开的话，你就再加一个任务，防止我忘记了」

## 要做的

- 两处界面上的「后台运行中」换成英文 `running`：
  - 命令转后台后对话里卡片的标题：现在是 `Background #3 · 后台运行中`（`crates/canter-tui/src/app.rs`），改成 `Background #3 · running`；
  - `/ps` 后台命令列表里还在跑的命令的状态（`crates/canter-tui/src/background.rs` 的 `status`），改成 `running`。跑完的照旧写 `exit code: N`。
- 测试里跟着这几个字写的断言一起改（`crates/canter-tui/tests/user_shell.rs`、`crates/canter/tests/tui.rs`），意思不变。
- DESIGN 里写「卡片标『后台运行中』」的地方改成写英文原文。

## 怎么算做完

- 终端界面上不再出现「后台运行中」，两处都显示 `running`。
- `crates/canter-tui/src` 里没有别的中文界面字符串（顺带查一遍，查到别的先列出来问主控，不自己改）。
- 验证：跑 `canter-tui` 和 `canter` 两个 crate 的测试，加 `cargo clippy --all-targets -- -D warnings`、`cargo fmt --check`、`git diff --check`。

## 不要做

- 不改后台命令的其他显示和行为。
- 不读、不改用户真实的 `~/.canter`；测试用隔离的 HOME。
- 不要按项目名或路径批量杀进程（`pkill -f canter` 这类）。
- 不合并到 main，不推送。
