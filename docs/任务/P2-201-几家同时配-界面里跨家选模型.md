## 要做成什么

1. `/model` 弹框列出所有已配的家的全部模型，可以直接选另一家的模型。
2. 每个模型能看出是哪一家的、上下文窗口多大、能不能看图，当前用的那个标出来。
3. `canter -m`、`canter exec -m` 能接带家名的模型名。
4. 换完以后状态栏的模型名和上下文数字（P2-79 标明压缩线或窗口的那个）按新模型显示。

- 状态栏的 `model` 一项：几家时显示 `<家名>/<模型名>`，只有一家时和现在一样。
