## 要做的

1. **存在哪**：全局记忆在 `<CANTER_HOME>/memory/`；项目记忆在 `<CANTER_HOME>/projects/<项目>/memory/`。项目按会话工作目录所在的 git 仓库认，同一仓库的多个 worktree 算同一个项目（用仓库的公共 git 目录认）；不在 git 仓库里就按工作目录本身。目录名你定，要稳定、不同项目不撞。目录权限 0700。
2. **一份记忆一个文件**：Markdown，开头写名字和一行简介（格式你定，写进 DESIGN）。canter 打开会话时从这些文件生成索引（一行一条：名字、简介、文件路径），不让模型自己维护索引文件。索引有上限（参照 Claude Code，超了只放前面的、并说明被截断），上限写进 DESIGN。
3. **读**：打开会话时把全局和项目两份索引放进系统提示，作为新的一段（种类、位置、稳定性照 DESIGN 第 20 条的规矩定，写进 DESIGN）。会话中途新写、改、删的记忆，本会话的系统提示不变，下次打开会话才更新。没有记忆就不出现这一段。
4. **写**：系统提示里告诉模型：什么值得记（用户偏好、被纠正的做法、项目约定、用户明确说「记住」的），什么不记（代码里看得出来的、只跟这次对话有关的、密钥和凭证），写到哪一层，怎么写文件，用户说「忘掉…」时怎么删或改。模型用现有的 write / edit 写记忆文件；对记忆目录（两层都算）免批准，开了沙箱时沙箱也放行，照会话临时目录的做法。只放开这两个目录，不放宽别的路径。
5. **提示词文字要用户同意**（DESIGN 第 20 条）：加进系统提示的英文文字（说明段和索引段的格式）写好后，**先停下来交主控**，用户同意了再接着做。和模型家族无关的写法，不写只对某一家成立的东西。
6. **受限会话**：没信任的文件夹开的会话（受限模式）不读记忆、不出现记忆段、不放开记忆目录。
7. **`/memory`**：列出全局和当前项目的记忆（名字、简介、哪一层），选中一个用外部编辑器打开（照 Ctrl+G 的做法），按键删（删前问一次，照 `/resume` 列表按 `d`）。没有记忆时说没有。列表的读、删走服务端协议（照 DESIGN 第 8 条写进 DESIGN），终端不直接读写记忆目录，以后桌面版和网页也能用。打开编辑器那一步可以在终端本机做。
8. **文档**：DESIGN 新加一条「记忆」，写明用户 11-01 定的四条和主控定的三条；`--help`、`?` 帮助里有 `/memory`。

屏幕上的字（命令说明、提示、报错）一律英文。
