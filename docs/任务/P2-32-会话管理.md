## 要做的

1. **删会话（服务端）**：加一个删会话的接口，由服务端把整个会话目录移到 `<CANTER_HOME>/trash/<id>`（目录不存在就建，权限 0700）。之后列表（`/v1/info`、`/v1/sessions`）、`-c`、启动预热都不再看到它，读它、恢复它报「会话不存在」。接口名和形状你定，照 DESIGN 第 8 条写进 DESIGN：和 Codex 的 archive 有什么不一样，为什么。`/v1/info` 的 features 加一项，让新终端连旧服务端时能给出清楚的提示。
2. **开着的不让删**：会话有终端挂着（P2-172 的客户端计数），或者没停下来（照 `finish_if_stopped` 的条件：在跑一轮、等批准或等回答、排队输入、目标续跑、后台命令会叫醒、`/btw`），服务端拒绝，返回能看懂的原因。服务端里加载着、但没人挂着而且停下来了的会话，先照常关掉，再移走。检查和移走之间不能让别的请求把它恢复、挂上或写进去：比如一边删、一边另一个终端恢复同一个会话，只能一边成功，不能出现删了一半或删完又被重新建出来。
3. **列表里删（终端）**：会话列表选中一个，按一个键删，删前问一次（Y/N 这类），删完列表里去掉它。键你定，不能和现有的键冲突，列表底部提示里写上。被拒绝时在列表里显示服务端给的原因。当前终端自己的会话也算「有终端挂着」，删不了。
4. **/rename**：`/rename <名字>` 改当前会话的名字，`/rename` 不带名字就清掉名字，都走现有的 `PATCH` 的 `name`。手动改过名以后，这个会话不再被自动起名覆盖（包括别的终端打开它时）。名字改完列表、状态栏里能看到。
