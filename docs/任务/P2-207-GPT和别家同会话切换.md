## 要做成什么

1. **GPT 的思考摘要不发给别家**：发 Chat Completions 请求时，GPT 产生的助手消息（带 `replay`、或能确定来自 Responses 的）里的思考摘要不进 `reasoning_content`；那条消息的文字和工具调用照发。DeepSeek、Kimi 等自己产生的思考照现在发（DeepSeek 带工具的轮次要回传思考，不能动）。没有 `replay` 的旧 GPT 消息分不清来源的，照现在发，写进完成记录。
2. **补丁调用转成文字**：目标模型没有 `apply_patch` 工具时（别家，或目录里不是 freeform 的 GPT），历史里的 apply_patch 调用和它的结果不再按函数调用发，改成一段标明来源的文字放在原位置（例如说明这是之前用补丁改文件的记录、补丁内容、执行结果），作为历史数据交给新模型，不伪造成新的工具调用、不重新执行。用户、助手角色不升格；结果文字标明是旧的工具输出。普通的 write/edit/shell/read 等调用照原样发。转换要确定：同一份历史每次翻译出的字节一样，不在已翻译的文字外再套一层。
3. **切回同一个 GPT**：照 P2-210 现在的规则，同模型同账号的旧 GPT 轮次照旧带加密思考和原输出项（包括 `custom_tool_call`），不改 replay 规则。
4. **辅助请求同一规则**：压缩、`/btw`、交接、下一句建议、子 agent 等用会话历史发请求的地方，按发给的那个模型走上面同一套翻译。
5. 来回切（GPT → 别家 → GPT → 别家）多次，每次发出去的请求都对；会话重开、服务端重启后翻译结果不变。

屏幕上的文字都用英文（本件预计不改界面）。
