## 重点看

1. **越权**：
   - 两种子 agent 的工具限制是不是在运行时拦住，而不只是不发工具定义；
   - 子 agent 拿不到子 agent 工具和 `ask_user`；
   - 主会话在计划模式或审查轮时只能开只读查找；
   - 权限档位实时跟主会话；
   - 记忆读不到、写不进；
   - 子 agent 批准框上的「本会话允许」只对这个子 agent 生效。
   - 有没有路径让子 agent 比主会话宽。
2. **并发**：
   - 新加的 `spawn_agent`、`wait_agent`、`send_input`、`close_agent`、叫醒、Esc 连带停，和删除、回退之间是否都按「先父后子」拿锁；
   - 有没有互相等待或漏掉的路径；
   - `wait_agent` 在 Esc 时能不能及时退出。
3. **批准转发**：
   - 子 agent 的请求在主会话事件流和快照里是否完整（开、解决、重开后还在）；
   - 用子会话接口回答后两边一致；
   - 主会话没有客户端连着时请求不会丢；
   - `canter exec` 下子 agent 和主会话一样自动处理。
4. **花费**：
   - 子 agent 花费算进主会话目标，到上限时子 agent 一起停；
   - `/usage` 算进子会话，没有重复计算。
5. **叫醒和结果交付**：
   - 交互会话做完叫醒一次，多个合并；
   - Esc 后不叫醒；
   - exec 下结果留到下一次输入，重开后交付一次、不重复；
   - 结果截断 32 KiB 且原结果保留。
   - 另外看 P2-177 遗留修复：启动时坏的子会话跳过、`/agents` 删除竞态。
