## 现状（主控查过的）

- 绘制在 `crates/canter-tui/src/app.rs`：`View::render` 从上到下画对话、状态行、`plan` 行、`list`（面板）、`Bottom`（输入框或批准框）、信息行。`list` 来自 `list_view`，依次是：子 agent 面板（`agents`）、选择框（`chooser`，如 `/model`、`/think`）、`/statusline` 设置（`setup`）、主题选择（`theme_picker`）、报告（`report`，`crates/canter-tui/src/report.rs`，`/mcp`、`/context`、`/files`、`/diff`、`/skills`、`/help`、`/usage`、`/goal`、`/lsp`、`/bg`、`/memory`、`/permissions` 等都用它），之后才是 Ctrl+R 历史搜索、`/` 命令列表、`@` 文件列表。
- 面板第一行是标题（`report::title`：粗体名字加暗色 ` · 说明`），最后一行是按键提示（`report::keys`，如 ` Esc close`、` ↑↓ select · Enter open · s stop · Esc close`）。放不下时上下滚动，显示上下还有几行。
- 上面这五类面板开着时，按键由它们处理（`agents_key`、`chooser_key`、`setup_key`、`theme_key`、`report_key`），输入框收不进字，但照样显示在下面。
- 批准框已经是「顶替输入框」的做法：`Bottom::Approval`，黄色圆角框，标题在上边框（`title_top`），按键在下边框（`title_bottom`），开着时 `list` 为空。

1. **哪些面板**：子 agent 面板、选择框、`/statusline` 设置、主题选择、所有报告（上面「现状」列的五类）。
2. **样子**：
   - 面板开着时，输入框不显示，它的位置换成一个圆角框装面板；Esc（或面板原来的关闭键）关掉后，输入框原样回来，草稿不丢。
   - 原来的标题行放到上边框左边（`╭─ 标题 ─…`），原来的按键提示行放到下边框右边（`…─ 按键 ─╯`），文字和颜色照旧（标题粗体加暗色说明，按键暗色）。框不比原来多占行：标题行和按键行变成了边框。
   - 边框用强调色（`theme` 里现有的强调色，比如 `/` 命令提示符用的那个），和灰色输入框、黄色批准框都不一样。颜色跟终端 16 色，不加底色。
   - 内容左右各留一格，放不下时照旧上下滚动、显示上下还有几行；窗口很窄、很矮时不崩，内容照旧裁切。
3. **不改的**：
   - 打字时的补全列表：`/` 命令列表、`@` 文件列表、Ctrl+R 历史搜索，照现在的样子画在输入框上面，输入框照常显示。
   - 批准框（黄色框）的样子和行为不变；批准框和面板同时出现时，照现在的先后规则。
   - 各面板的内容、按键、行为一律不变，只改外框和摆放。
   - 对话、状态行、信息行不变。
4. **DESIGN** 第 19 条展示层补一句：面板用强调色圆角框顶替输入框，标题和按键在边框上；补全列表照旧。
