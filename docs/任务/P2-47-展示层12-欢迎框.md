## 小马的像素

16 列 × 8 行像素。终端里一个格子上下两个像素（上半块 `▀`、下半块 `▄`、整块 `█`；上下两个像素颜色不同时用前景色画上半、背景色画下半），所以占 16 列 × 4 行。`.` 是空（终端背景）：

```
..........b..b..
........mmbbbbb.
.......mmbwebbbb
.......mbbeebbbb
.mm....mbbbbbpcc
m..bbbbbbbbbbcc.
...bbbbbbbbb....
...m.m...m.m....
```

| 字母 | 是什么 | 真彩色 |
|---|---|---|
| `b` | 栗色身体 | `#c0703f` |
| `m` | 深棕鬃毛、尾巴、蹄子 | `#5b3220` |
| `e` | 眼睛 | `#1e1a18` |
| `w` | 眼睛高光 | `#ffffff` |
| `c` | 奶油色鼻头 | `#f1d2a6` |
| `p` | 粉色腮红 | `#e89a8c` |

- 256 色终端：每种颜色取 256 色里最接近的一个，写进 `theme.rs`；浅色终端里眼睛和身体也要分得开。
- 16 色终端：整匹马用主色（青色，`theme::accent`）画轮廓，眼睛（`e`、`w`）留空。
- 不要颜色（`NO_COLOR` 等，`theme.rs` 的 `Depth::None`）：用默认前景色画轮廓，眼睛留空。
