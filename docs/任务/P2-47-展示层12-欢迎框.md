## 要做的

- **框里的内容**：
  - 第一行 `canter <版本号> · <提交号>`。提交号是编译时 git 的短提交号，工作区有没提交的改动时后面加 `-dirty`。编译时拿不到 git（不在 git 仓库里、没装 git）就只写版本号。
  - 第二行工作目录的完整路径，家目录写成 `~`，太长从中间省略。
  - 空一行，再两行快捷键提示，内容照「样子」。只列已经有的键：`/help`、`@`、Ctrl+F（P2-44）、Ctrl+O、Shift+Tab、Esc、Ctrl+C。
  - 框线和提示用次要颜色，名字和版本号正常颜色。
- **什么时候有**：每次打开 canter 都画在对话最上面，新会话和接着旧会话都有；接着旧会话时往上翻到头才看得到。跟着对话往上滚，不常驻屏幕。切换会话（会话列表）后照新会话的目录画。
- **不进会话**：只在终端里画，不写进会话存档，不发给模型；`/rewind`、压缩不影响它。P2-45 选字复制能选到框里的字，框线算装饰；P2-44 搜索搜得到框里的字。
- **窄窗口**：放不下框时退成不带框的几行字；快捷键提示放不下就从后往前少显示几个，不折行。
- **`canter --version`**：打印 `canter <版本号> · <提交号>`（和框里第一行一样）后退出，不连服务端。`-V` 同义。`canter --help` 如果有，加上这一项。
- 提交号只在一处算出来（编译脚本，`build.rs`），终端界面和 `--version` 用同一个值。
- README 写欢迎框和 `--version`。
