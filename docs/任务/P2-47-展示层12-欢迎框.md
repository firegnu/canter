## 小马的像素

16 列 × 8 行像素。终端里一个格子上下两个像素（上半块 `▀`、下半块 `▄`、整块 `█`；上下两个像素颜色不同时用前景色画上半、背景色画下半），所以占 16 列 × 4 行。`.` 是空（终端背景）：

```
..........b..b..
........mmbbbbb.
.......mmbwebbbb
.......mbbeebbbb
.mm....mbbbbbpcc
m..bbbbbbbbbbcc.
...bbbbbbbbb....
...m.m...m.m....
```

| 字母 | 是什么 | 真彩色 |
|---|---|---|
| `b` | 栗色身体 | `#c0703f` |
| `m` | 深棕鬃毛、尾巴、蹄子 | `#5b3220` |
| `e` | 眼睛 | `#1e1a18` |
| `w` | 眼睛高光 | `#ffffff` |
| `c` | 奶油色鼻头 | `#f1d2a6` |
| `p` | 粉色腮红 | `#e89a8c` |

- 256 色终端：每种颜色取 256 色里最接近的一个，写进 `theme.rs`；浅色终端里眼睛和身体也要分得开。
- 16 色终端：整匹马用主色（青色，`theme::accent`）画轮廓，眼睛（`e`、`w`）留空。
- 不要颜色（`NO_COLOR` 等，`theme.rs` 的 `Depth::None`）：用默认前景色画轮廓，眼睛留空。

## 要做的

- **右边四行字**：
  - 第一行 `canter <版本号> · <提交号>`，`canter` 加粗。提交号是编译时 git 的短提交号，工作区有没提交的改动时后面加 `-dirty`。编译时拿不到 git（不在 git 仓库里、没装 git）就只写版本号。
  - 第二行工作目录的完整路径，家目录写成 `~`，太长从中间省略。
  - 第三、四行快捷键提示，内容照「样子」。只列已经有的键：`/help`、`@`、Ctrl+F（P2-44）、Ctrl+O、Shift+Tab、Esc、Ctrl+C。
  - 后三行用次要颜色。
  - 字和小马之间空 3 列，四行字和小马的四行对齐。
- **小马**：照上面「小马的像素」画，三种色深各按那一节的规则。
- **什么时候有**：每次打开 canter 都画在对话最上面，新会话和接着旧会话都有；接着旧会话时往上翻到头才看得到。跟着对话往上滚，不常驻屏幕。切换会话（会话列表）后照新会话的目录画。
- **不进会话**：只在终端里画，不写进会话存档，不发给模型；`/rewind`、压缩不影响它。P2-45 选字复制选得到右边的字，小马算装饰、不复制；P2-44 搜索搜得到右边的字，搜不到小马。
- **窄窗口**：放不下小马加字时只显示右边的字（顶格）；快捷键提示放不下就从后往前少显示几个，不折行。
- **`canter --version`**：打印 `canter <版本号> · <提交号>`（和第一行一样）后退出，不连服务端。`-V` 同义。`canter --help` 如果有，加上这一项。
- 提交号只在一处算出来（编译脚本，`build.rs`），终端界面和 `--version` 用同一个值。
- README 写欢迎头和 `--version`。
