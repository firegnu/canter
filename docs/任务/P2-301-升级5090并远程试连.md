## 要做的

1. **升级 5090**：在 `~/canter-linux/canter` 里 `git pull`、`canter upgrade`，再 `canter serve --replace` 换上新服务端（HANDOFF 已知问题：Linux 上不换服务端，`@` 补全起不了文件遍历）。`canter --version` 和服务端 `/v1/info` 都是新版；`canter doctor` 看默认会话环境（P2-295 第一次在 Linux 上跑）。
2. **5090 本机先用一下**：分支名、`/diff`、`@` 补全、`!which <常用命令>`，确认和以前一样。
3. **5090 开远程端口**：`config.json` 加 `"remote": {"listen": ["127.0.0.1:<端口>"]}`，`canter serve --replace`，`canter remote token add mac` 发一个令牌（只显示一次，由用户自己复制，不经过主控，不写进任何文件和对话记录之外的地方）；`canter doctor` 看监听和令牌。
4. **隧道**（照 `docs/remote.md`）：5090 `ssh -R` 把端口挂到 `gcp-relay` 的回环地址；Mac `ssh -L` 把它转到 Mac 的回环地址。先手动开，自动重连留给 P2-300。
5. **Mac 连上去**：`canter remote add 5090 http://127.0.0.1:<Mac 端口>`（令牌从标准输入粘，不回显），`canter remote list`、`canter doctor --server 5090`，然后 `canter --server 5090 --cwd <5090 上的项目路径>`。
6. **远程试用**：聊天和改代码、跑命令、批准、打断；分支名和改动行数、`/diff`、`/files`、`@` 补全、`/review`、贴图；关掉终端再 `-c` 接上；人为断一下隧道再接上，看续接；`canter exec --server 5090` 跑一次。
7. **记下来**：延迟和流式输出的感觉、断线后多久能接上、碰到的问题，写进本文件「完成记录」。问题要修的，另开任务。
