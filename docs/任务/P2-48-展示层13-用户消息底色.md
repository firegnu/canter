## 要做的

- **铺哪些**：对话里已发出的用户消息（包括带图片的、review 轮的标题行按用户消息算的那种，照 P2-42 的归类）。排队中、还没被模型处理的消息不铺，照现在。
- **怎么铺**：
  - 底色铺满对话区整行宽度，文字后面空出来的格子也铺。
  - 消息上下各多一行同色的边（空的、铺底色的一行）。边的外面照 P2-42 的规矩各留一行普通空行和别的项目隔开，不叠成两行空行。
  - `›` 和文字的颜色不变；多行消息每行都铺；窄窗口折行后每一行都铺。
- **颜色**：深色终端用比背景稍亮的灰，浅色终端用稍暗的灰；真彩色和 256 色各定一个值，加到 `theme.rs` 里，和 diff 底色同一套 `bg(dark, light)`。灰度要淡，不抢文字；256 色下要还能看出来（P2-36 踩过：256 色里有的颜色会被映射成别的）。16 色、不知道深浅、`NO_COLOR` 时不铺，照现在。`CANTER_THEME` 强制深浅时照它。
- **和前几件一起**：P2-45 拖选复制时，底色边那两行和文字后面补的空格不算内容；P2-44 搜索、P2-45 选中的反白在底色上照样看得清（反白盖过底色）；P2-47 欢迎框不铺。
- README 讲颜色的地方加上用户消息的底色。
