类型：功能变更
依据：10-26 用户加的。照 Claude Code：消息发出去后、模型还没开口之前按 Esc，这一轮取消，消息从对话里撤掉（模型以后也看不到它），全文回到输入框。要改终端界面，可能还要改服务端（撤掉一轮可以借 P2-23 退回对话的办法）。
