## 用户试用时看到的（10-26）

- 用户让模型「运行 ls /no-such-dir」，模型跑的是 `ls /no-such-dir; echo "exit code: $?"`，整条命令退出码是 0，卡片显示绿色 `exit 0`，失败被藏起来。canter 卡片本来就显示退出码，系统提示词可以写明：照用户给的命令跑，不要自己在后面加 `echo $?` 这类东西。
