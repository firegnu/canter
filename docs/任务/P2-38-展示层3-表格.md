## 要做的

照方案第 4 项「推荐」做，要点：

- **开 pulldown-cmark 的表格扩展**，画成框线表格：框线灰色（`theme.rs` 的「次要」），表头粗体，表头下一条分隔线。数据行之间平时不画线；有格子折成多行时才在行和行之间画线。
- **对齐**：照 `:---`、`:---:`、`---:` 左、中、右对齐，没写的左对齐；表头跟着本列。
- **中文**：宽度按显示宽度算（unicode-width），中文和全角标点算 2 列，用空格补齐；格子里的粗体、行内代码照样上样式。
- **比屏幕宽**：
  1. 先按每列最宽的内容排，放得下就这样；
  2. 放不下：每列至少留住本列最长的一个词（最多 16 列，再长的也断），剩下的宽度按各列还差多少按比例分，格子里折行；
  3. 还放不下（平均一列不到 6 列）：改成一条条记录，每行一块「表头: 值」，块之间一条灰线。
- **流式**：表格每来一行就整张重排。
- `markdown::render` 和 `cells::agent_message` 加一个可用宽度的参数；宽度变了照旧整段重画。
- 不加依赖（pulldown-cmark 的表格扩展是现有库的选项）。要加依赖，停下来问。
- README 里讲 markdown 显示的地方写上表格的规则和已知限制（终端把「东亚模糊宽度」字符画成 2 列时会错位，个别 emoji 可能错一格）。
