## 要做的

1. **颜色**：`theme::shell()` 从红改成终端自带的品红（`Color::Magenta`）。输入框边框、提示符 `!`、提示文字、对话里用户跑的命令卡片的 `!`，都用这个颜色。
2. **进 shell 模式**：草稿算 `!` 命令时（规则不变：去掉开头空白后以 `!` 开头），输入框开头的 `› ` 换成品红的 `! `，草稿里那个 `!`（连同它前面的空白）不再画在文字里。光标停不到 `!` 前面。
3. **出 shell 模式**：shell 模式下草稿除了 `!` 是空的，按退格就回到普通输入（`› ` 回来，边框变回原色）。草稿还有字、光标在最前面时按退格，什么都不做，免得命令变成发给模型的话。
4. **提示**：shell 模式下，输入框的下边框上画品红的 `! for shell mode`，靠左；不占行、不挤掉下面的状态栏。
5. **跑完回到普通输入**：发出以后输入框清空，回到 `› `。
6. 沿用现有机制：草稿里仍然存着 `!`，只是画法变，所以发送、输入历史（翻到一条 `!` 命令时直接是 shell 模式）、Tab 插队、打断后放回输入框、外部编辑器这些照旧按「以 `!` 开头」判断，行为不变。模型干活时打 `!` 的那句黄色提示照旧。
