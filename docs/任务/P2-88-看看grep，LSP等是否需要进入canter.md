## 要做的

1. **对照表**：Codex、pi、opencode、Claude Code 各自内置了哪些工具（名字、做什么、主要参数、输出上限、要不要批准），和 canter 现在的 7 个对齐列一张表。各家默认开着的和要配置才开的分开标。
