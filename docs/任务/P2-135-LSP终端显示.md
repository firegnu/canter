## 要做的

界面上的字样下面已经定好（英文，canter 界面都是英文），照写；括号里的中文只是说明，不上屏。

1. **改文件卡片**：write / edit 卡片下面多一行，次要信息的灰色（有错误时 `LSP:` 后面的数字用失败色），按 `diagnostics` 项目的状态写：
   - 有结果：`LSP: 2 errors, 1 warning`（单复数照数量）；没有错误和警告：`LSP: no errors or warnings`
   - 等待中：`LSP: pending`；不可用：`LSP: unavailable`（Ctrl+O 展开看原因）
   - 时效不是 current 时在后面加：` · version unconfirmed`、` · may be stale`、` · incomplete`；文件删了：`LSP: file deleted`
   - Ctrl+O 展开后逐条列 `{path}:{line}:{column} {error|warning} [{source}/{code}] {message}`（行列从 1 起，没有的部分省掉），以及不可用、不完整的原因。
   - LSP 的状态不影响卡片本身的成功 / 失败颜色。没有 `diagnostics` 项目（LSP 关着、文件没有对应的服务器）时卡片和现在一字不差。
   - 晚到的诊断是单独一项，照同样的写法，开头写 `LSP update: {path}`，例如 `LSP update: src/main.rs · 1 error`。
2. **`/lsp` 弹框**：照后台命令弹框的做法：列表 → 选中按 Enter 看详情。
   - 标题：` LSP  {N} server(s)`（单复数照数量）。
   - 列表每个服务器一行：状态圆点 + 名字 + 项目根（家目录写成 `~`）+ `{state} · {memory} · {N} session(s)`。状态照 `LanguageServerState` 写小写英文：`starting`、`running`、`stopped`、`unavailable`、`reconnecting`；内存按 `rssBytes` 写成 `312 MB` 这类，没有就省掉。有 `reason` 时下面缩进一行写出来。
   - 列表底行：` Enter details · Esc close`。
   - 详情：上面同一行的全部信息加 `reason`，再加一句 ` Stop applies to this session only; other sessions keep their own.`；底行 ` s stop · r retry · Backspace list`，`s` / `r` 调 P2-134 的停止 / 重试端点，结果刷新到弹框里，失败时把错误写在弹框里。
   - 没有服务器时：` No language servers for this session.`，下面灰色一行 ` LSP is off by default. To turn it on, set lsp.enabled in ~/.canter/config.json and run canter serve --replace.`（canter 分不清「LSP 关着」和「还没起服务器」，所以两句都写）。
   - 服务端太旧（`GET /v1/info` 的 `features` 里没有 `lsp`）：` This canter server does not support LSP. Run canter serve --replace.`
3. `?` 帮助和 `/help` 加 `/lsp`：`Show language servers`。导出带上诊断那一行和晚到的诊断项。从历史打开会话、另一个终端打开同一个会话，看到的一样。
