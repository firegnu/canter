## 要做的

1. **协议加输入类型 `image`**：写法照 Codex，`{type: "image", url: "data:image/png;base64,…", name?}`。服务端只收 data URL，不去抓 http 图片。
2. **服务端处理**：
   - 解码，核对类型和大小，沿用单张 8 MiB 的上限；
   - 存一份会话副本，事件里照旧写成 `localImage` 加副本文件名，所以事件和会话记录的格式不变。
3. **`localImage` 保留**：语义写明是「服务端机器上的路径」，供本机外部集成用。
4. **请求体上限**：只对新建会话和发输入这两个接口放宽，按图片张数乘 8 MiB 再乘 4/3 算；别的接口不变。
5. **终端**：剪贴板截图和拖进来的文件，改成读出内容、交字节，本机和远程都这样，不留「本机交路径」的老路。撤回再编辑照旧可用。去掉 P2-297 加的远程贴图提示。
6. **兼容**：
   - `/v1/info` 的 `features` 加 `imageData`；
   - 新终端连上没有这个能力的旧服务端时，贴图提示 `serve --replace`，沿用现在的能力提示写法。
7. **文档**：协议 README 加 `image` 输入；DESIGN 里写贴图的地方跟着改。
