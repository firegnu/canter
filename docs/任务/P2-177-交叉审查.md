## 重点看

1. **数据**：`parent` 是否和会话创建一起原子落盘，子会话不会短暂出现在普通列表里；旧存盘没有这些字段时照普通会话读；子会话状态和最终回复重开（重放事件）后和运行时一致。
2. **并发**：父会话和子会话按「祖先在前」拿操作锁，删、回退和同时新开子会话之间会不会死锁或漏掉刚开的子会话；连带进回收站或回退时中途失败，会不会留下一半移走、一半没移的状态。
3. **权限继承**：子会话继承的权限档位、沙箱、工作目录、新增目录、环境变量是否和父会话一致；有没有路径让子会话比父会话权限更宽（比如父会话是受限打开、没信任的文件夹，子会话变成不受限）。
4. **重启**：重启时只把没做完的子会话标成中断，不影响普通会话，重复启动不重复记。
5. **列表**：`--resume` 列表、`canter stats` 列表、`canter -c`、`canter exec --last` 都不选子会话；按 ID 打开子会话照常可用。
