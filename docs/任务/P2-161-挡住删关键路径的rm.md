## 要做的

1. **什么算命中**：模型 shell（前台和后台）里任一段是 `rm` 或 `rmdir`，且目标里有下面任一种（不看选项，`rm ~/*` 不带 `-r` 也算）：
   - 根目录 `/`，根下一级目录（`/usr`、`/etc`、`/Users` 这类）；
   - 家目录本身；
   - 会话的工作目录本身和它的各级上级；加进来的目录（P2-118，`PermissionGate` 的 `additional_directories`）本身和它们的上级；
   - 工作目录、加进来的目录下面一层的通配（`rm -rf *`、`rm -rf ./*`）；
   - 认不清目标的：目标里有变量、命令替换、反引号（`rm -rf "$DIR"/*`、`rm -rf $(cat list)`），或者这一段 canter 解析不了、排除不了它删的是关键路径。

   路径先规范化再比：`~`、`..`、`.`、多余的 `/` 和末尾的 `/`；相对路径按工作目录和同一条命令前面的 `cd` 算（照只读白名单已有的 `cd` 跟踪；`cd` 的目标判断不了的，后面的相对路径算认不清）。不跟符号链接。
2. **要认得出的写法**：选项任意顺序和拼法（`-rf`、`-fr`、`-r -f`、`-Rf`、`--recursive --force`）；带路径的程序（`/bin/rm`、`/usr/bin/rm`）；前置变量赋值（`X=1 rm …`）；包装命令（至少 `sudo`、`env`、`timeout`、`time`、`nice`、`nohup`、`command`、`exec`、`xargs`）；控制结构里的（`if …; then rm …; fi`、`for … do rm …; done`、`! rm …`）；组合命令里任一段（`;`、`&&`、`||`、`|`、换行）；`$(…)`、`${…}`、括号、花括号之后的段；`bash -c`、`sh -c`、`zsh -c` 引号里的字面命令。脚本、`make`、`npm run` 里面的不管（看不到）。
3. **命中后**：
   - 「全部允许」：拒绝，不弹框，不执行。模型收到英文说明，照这个意思写：`Blocked: rm/rmdir on a critical path (<命中的目标>). canter refuses this in allowAll mode. If the user really wants it, they can run it themselves with !.`（认不清目标时 `<命中的目标>` 写原文那个词，比如 `"$DIR"/*`）。
   - 「总是问」「只问执行」：一定弹框问，`rules.json` 的放行规则（包括用户手写的 `rm` 放行）和会话前缀都免不掉；批准框不给「本会话放行」「以后都不问」。用户点允许就执行。
   - `rules.json` 的禁止规则照旧优先（命中禁止就拒绝）；计划模式、审查轮照旧；用户自己敲的 `!` 命令不管。
4. **DESIGN**：在「按命令放行（P2-108）」一节里写上这个内置判断：管什么、三档下怎么处理、规则免不掉、不管什么（脚本内部、别的危险命令）。原来「全部允许只看禁止」那句改对。写上第 5 条的接口：以后加一种危险命令就是加一个检查。
5. **做成能插的检查**（用户 10-30 定，见「用户原话」）：危险检查做成统一接口，像 P2-106 搜网页的 `SearchProvider` 那样。
   - 每个检查只回答一件事：这一段命令（已经剥掉包装、认出程序名、规范化路径之后的结果）危不危险；危险就给一句英文原因。拆段、剥包装、路径规范化这些是公共的，放在检查外面，所有检查共用。
   - 命中后怎么处理（「全部允许」拒绝并让用户用 `!` 跑；另外两档一定弹框、放行规则和会话前缀免不掉、不给两项前缀选项）由核心统一做，不归各个检查管。第 3 条的说明改成通用格式，把检查给的原因填进去，照这个意思写：`Blocked: <检查给的原因>. canter refuses this in allowAll mode. If the user really wants it, they can run it themselves with !.`，删关键路径这个检查给的原因比如 `rm/rmdir on a critical path (<命中的目标>)`。
   - 检查列表写在一处；以后加 `git reset --hard`、`git push --force` 这类，就是加一个检查文件、加它自己的测试、在列表里加一行，核心不动。
   - 本件只实现「删关键路径的 rm/rmdir」这一个检查。不做用户自己写脚本挂进来的检查（那是 P2-153 hooks），不加配置开关。
