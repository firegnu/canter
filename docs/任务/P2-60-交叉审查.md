## 重点看

1. **隐私**：`config.json` 里的 API key 和别的项，会不会进到命令的输入 JSON、日志、报错或内存里留着的值。JSON 字段是不是只有任务列的那些。
2. **子进程**：
   - 超时、换会话、退出终端时，命令和它起的子进程能不能都停掉。
   - `killpg` 用进程组号，进程已经退出时会不会误杀别的进程组。
   - 输出很多或不停输出时，会不会卡住或吃内存。
   - 同一时间只跑一个；跑着时又有变化，最后一次变化一定会跑到。
3. **画面安全**：命令的输出只保留 SGR 颜色，别的控制字符和转义序列（包括 OSC、双向文字控制符）能不能进到终端。宽字符截断对不对。
4. **Shift+Tab**：照上面主控补定的规矩，P2-20 原来的拦截有没有被打破，尤其是命令一次都没成功过、命令的输出刚出来那一帧、换会话这几种时候。
5. **不配置时**：和 main 完全一样，不跑任何命令，不多读文件以外的东西；TPS 的估算和用真实值切换对不对。
