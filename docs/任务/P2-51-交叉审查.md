### 意见

1. 建议改：`crates/canter-tui/src/app.rs:3048`（`KeyCode::Backspace | KeyCode::Up if text.is_empty() => cursor.custom = None`）。
   - 问题：从写字行回到选项时，300 毫秒保护期不会重新开始（保护期只在同一个请求第一次显示回答时开始）。按住退格删字，多删一下就回到了选项，接下来打的数字直接被当成回答：`1` 执行这一次，`2` 给整个会话授权。用户本来要拒绝，结果变成了执行。临时测试证实了：写 `x`，按两次退格（每次都重画），再按 `2`，得到 `Resolve { decision: AcceptForSession }`。提问框也是这么写的，但那边选错只是答错一题，这边是执行工具。没定成「必须改」，因为这正是任务书定的「空着按退格或 ↑ 回到选项」「保护期照旧」，代码没有违背任务书。
   - 改法：只在批准框（不动提问框）从写字行回到选项时，把 `guard_until` 推到 `按键时刻 + ANSWER_GUARD_MS`，等于选项重新弹出一次。可以让 `approval_key` 拿到按键时间来做，也可以在 `frame_on_screen` 里把「同一个批准请求从写字行换回选项」当成回答重新出现。这只挡得住接着连打的情况，停顿超过 300 毫秒后再打数字还是会被当成回答。更彻底的办法是批准框里只有 ↑ 回选项、退格不回，但这改了用户定的规矩，要先问用户。
2. 建议改：测试缺口。
   - 问题：有两处任务书没要求测、开发方照「不要自己加」也没加，但都落在这次碰的要害上：
     - `approvalFeedback` 在回退对话（P2-23）、撤回（P2-59）后去掉被删项目的说明（`crates/canter-protocol/src/reducer.rs` 约 330 行），没有自动测试。
     - 提问框请求带 `feedback` 会被拒，也没有测试。
   - 我用临时测试确认现在的行为是对的。
   - 改法：在 `crates/canter-protocol/tests/approval.rs` 加一条归并测试，回退对话、只回退代码、撤回各一种情况；`decline_feedback_tests.rs` 加一条提问框带 `feedback` 的用例，断言 `invalid_decision`、快照不变。要不要补由主控定。
3. 可以不改：`crates/canter-tools/src/permission.rs:72`。
   - 问题：闸门自己不管 `feedback` 和 decision 是不是配得上：`Decline` 带了 `feedback`，照样把话交给模型；`DeclineWithFeedback` 没带，就退成普通拒绝。能不能这样配，只靠 `Session::resolve_inner` 事先拦。不过这两种结果都是拒绝，执行不到；现在唯一的调用方也拦了，文档注释里写了要调用方先校验。
   - 改法（想更稳的话）：闸门里只有 `DeclineWithFeedback` 才保留 `feedback`。
4. 可以不改：`crates/canter-tui/src/cells.rs:269`。
   - 问题：说明用的是 `sanitize`。单独一个 `\r` 会把这一行前面的字清掉（当成进度条处理），双向控制字符（U+202E 这类，Rust 的 `is_control` 不算它们）也不去掉。终端自己交出的说明里不会有这些：打字时滤掉了控制字符，粘贴时 `clean` 把换行变成了空格。只有别的客户端通过 API 交的才可能带。模型拿到的是原话，不丢。对话里其它服务端文字也是这么处理的。
   - 改法（要改的话）：给说明单独用一个版本，把 `\r` 当空格，并去掉双向控制字符。
5. 可以不改：`crates/canter-core/src/session.rs:716`。
   - 问题：先校验 `feedback`，后看请求类型，所以提问框请求带了 `feedback`，报的是 `invalid_decision`，不是 `invalid_request`。请求确实被拒了，也还在等，任务书只要求拒掉，满足了。
   - 改法：不用改。想让错误码更贴切，可以把这条校验挪进 `RequestKind::Approval` 分支，提问框分支另外检查 `feedback.is_none()`。
6. 可以不改：`docs/DESIGN.md` 第 8 条和 `crates/canter-protocol/README.md`。
   - 问题：只写了「回退对话时移除已删项目的说明」，代码在撤回（`turn.retracted`）时也会去掉。
   - 改法：补上「回退对话、撤回时」。
