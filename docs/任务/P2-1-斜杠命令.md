## 要做的

### 命令列表

输入框里第一个字是 `/` 时，在输入框上方弹出命令列表，每行「命令名 + 一句英文说明」，跟着已输入的字过滤。上下键选，Tab 补全成选中的命令，Enter 执行选中的命令，Esc 或删掉 `/` 收起。样子照常见做法（Codex、Claude Code 都这样）：

```
 /compact   Summarize the conversation to free up context
>/exit      Quit canter
 /help      Show available commands
──────────────────────────────────────────
> /e
```

界面文字用英文（P1-11），颜色和边框沿用现有的批准框、会话列表，不另起一套样式。

### 6 个命令

- `/help`：在会话里显示命令和说明，只显示，不发给模型。
- `/exit`：退出，和现在空输入框按 Ctrl+D 一样（会话留在服务端，退出时照旧打印怎么接着聊）。
- `/new`：在同一个终端里开一个新会话，目录、模型、权限模式沿用当前会话；旧会话照现在退出时那样留在服务端，不关。
- `/resume`：弹出现在的会话列表（`picker.rs`），选了就在本终端换到那个会话，Esc 回到原会话。
- `/compact`：压缩当前会话（已有的 compact 接口），进度和结果照现有的压缩事件显示。
- `/mode`：换权限模式。`/mode always-ask`、`/mode ask-for-execution`、`/mode allow-all` 直接换；不带参数弹出三选一，当前的那个标出来。换完状态栏跟着变（走已有的 `PATCH` 和 `session.updated`）。

### 换会话时屏幕上的旧内容（主控定）

界面是全屏的（P2-16，DESIGN 第 18 条）。`/new`、`/resume` 换过去时，对话区整个换成新会话的历史，回到跟着最新输出；在新会话历史的最上面不加东西，换到哪个会话看信息行。旧会话还在服务端，用 `/resume` 能换回去。

### 分辨命令和普通消息（主控定）

- 第一个词以 `/` 开头、词里不再有别的 `/` 的，算命令：认识的执行；不认识的在会话里提示 `Unknown command: /xxx`，不发给模型，草稿留在输入框里。
- 第一个词里还有别的 `/`（比如 `/tmp/a.txt 看看这个`）的，当普通消息发出去，不弹列表也不报未知命令。

### 其他

- 命令只在输入框里用；批准框开着时不弹列表。P1-14 的发送保护期照样挡 Enter，执行命令的 Enter 也挡。
- 命令执行失败（比如服务端拒绝在回答中途压缩）用现有的 warning 显示服务端的错误，不崩、不退出。
- 后面的件要往列表里加命令：命令的名字、说明、执行写在一处，加一条命令只改那一处（要碰协议的另说）。
