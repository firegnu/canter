P2-255 Sub-agents 框加「深度」「任务」· 线框

4 个问题，每题列出可选样子，橙框是主控的推荐。界面上的字都是英文；任务内容是模型写的，所以这里是中文。例子用 11-08 测试时那两个子 agent。

主控的推荐，一句话版
  1. 深度、任务各占一列，排在类型后面、时间后面；一个子 agent 仍是一行。
  2. 终端窄时先缩任务列，太窄就整列不显示；深度列一直在。
  3. 任务全文用弹框盖在对话区上面，Esc 只关弹框。
  4. 选中一行按 t 或点任务那一列打开弹框；Enter 照旧打开子 agent 的会话。

1. 深度和任务在列表里怎么摆

平时展开 Sub-agents 框时看到什么？

A. 各占一列，一个子 agent 一行推荐

╭ Sub-agents · 1 running · 1 done ────────────────────────────────────────────────╮
   Main session · 对比 /tmp/codex 和 /tmp/pi-mono 这两个项目是怎么处理…      (here)
 › ├ ● codex tool timeout study  explorer  medium  running  8m 52s  只研究 /tmp/codex 这… 
   └ ✓ pi-mono timeout study     explorer  medium  done     4m 30s  只研究 /tmp/pi-mono…
╰─────────────────────────── ↑↓ select · Enter open · t task · s stop · Esc close ╯
  • 就是你说的「加一列深度、再加一列任务」。行数不变，框不变高。
  • 任务列只放第一行，放不下就截断，用 … 结尾。
  • 深度颜色：quick 灰、medium 黄、thorough 品红，一眼分得出。以前开的子 agent 没有深度，显示灰色 —。

B. 深度并进类型，任务另起一行

╭ Sub-agents · 1 running · 1 done ──────────────────────────────────╮
   Main session · 对比 /tmp/codex 和 /tmp/pi-mono …       (here)
 › ├ ● codex tool timeout study  explorer · medium  running 8m 52s 
   │   只研究 /tmp/codex 这个项目（Rust 里的 codex CLI…）是如何…        
   └ ✓ pi-mono timeout study     explorer · medium  done    4m 30s
       只研究 /tmp/pi-mono 这个项目（一个 monorepo，里面应该有…
╰──────────────────── ↑↓ select · Enter open · t task · s stop · Esc close ╯
  • 任务能多显示一些字。
  • 每个子 agent 占两行，4 个就是 8 行，框明显变高、挤对话区。
  • 不是你说的「加列」。

4. 用什么键打开

现在 Enter 是「打开子 agent 的会话」，点一行也是。

A. 新加 t，点任务列也行；Enter 不变推荐

╰────────── ↑↓ select · Enter open · t task · s stop · Esc close ╯
  • 你已经习惯的 Enter、点一行打开会话都不变。
  • 鼠标点这一行的任务那一列 → 弹框；点名字、状态等其它位置 → 照旧打开会话。
  • 选中最上面 Main session 那行时，t 不做事。

B. Enter 改成弹框，打开会话换成 o

╰────────── ↑↓ select · Enter task · o open · s stop · Esc close ╯
  • 看任务更顺手。
  • 改了已有习惯，点一行到底是弹框还是打开会话也要重新定。

附：深度从哪来

  • 现在深度是模型写在任务正文里的，写法不固定（GPT 写 medium depth — …，DeepSeek 写「深度：medium」），没法可靠地拆成一列。
  • 所以给 spawn_agent 加一个必填参数 depth，只能填 quick / medium / thorough。服务端把对应的一句英文说明接在任务后面交给子 agent，列表直接显示这个值。
  • 任务列和弹框里显示的是模型写的任务，不含服务端接上的那句；深度只在深度列和弹框标题里出现。
  • 对话里的 Spawned 卡片（Ctrl+O 看全文）和 /export 不改。
