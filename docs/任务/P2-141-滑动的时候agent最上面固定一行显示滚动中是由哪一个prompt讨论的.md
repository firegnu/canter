## 要做的

1. **什么时候显示**：只在往上翻着（`Scroll.top` 不是 `None`）、并且对话区最上面那一行所属的那条用户消息已经整条滚出屏幕上方时显示。「所属」指对话区最上面那一行之前最近的一条用户消息。最上面那一行还在第一条用户消息之前（欢迎头那里），或者那条用户消息有一部分还在屏幕上，就不显示。跟着最新输出时（没往上翻）不显示。
2. **显示什么**：对话区最上面一行，灰色（照界面现有的次要文字颜色），写 `› ` 加那条用户消息的第一行非空文字；一行放不下就截断，末尾 `…`，按显示宽度算（中文宽字符）。用户消息只有图片、没有文字时写图片标记那样的文字（比如 `[Image]`），具体照现有的画法定。
3. **占位**：照底部那行提示，占对话区的一行（对话少显示一行），不盖在对话上面。窗口太矮、对话区放不下时先不显示它。
4. **点了跳回去**（照 Claude Code）：单击这一行，对话滚到那条 prompt（它的第一行在对话区最上面，照「往上翻着」的状态，不回到跟着最新输出），这一行藏起来，直到用户再滚动（滚轮、PgUp/PgDn、拖到边沿自动滚这类）才按第 1 条重新判断。单击的判定和点链接一样按画出来的那一帧算。
5. **不是对话的一部分**：拖选复制不会选到这一行，在这一行上不打开链接，对话搜索不搜它。
6. 算哪些消息：只算已经发出去、显示在对话里的用户消息（包括 `/init` 这类发出去的固定提示词）；排队中还没发的不算。`!` 跑的命令、技能提示行照现在的画法，不算用户消息。
