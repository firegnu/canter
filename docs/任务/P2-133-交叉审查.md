## 重点看

1. **不拖累原来的工具**：`lsp.enabled` 关着时，write / edit / 回退 / shell 的行为和耗时跟以前一样；开着时，write / edit 不等语言服务器；shell 结束时会 `await` 核对（`shell.rs` 的 `control.reconcile().await`），语言服务器卡住或很慢时会不会把 shell 结果拖很久、或卡住整轮；失败、被拒绝的写入不通知；只用 shell 的会话不起服务器。
2. **结果对不对得上内容**：版本按实例内同一文件递增（删除后重开、64 个回收后重开都不复用旧版本）；旧版本、旧实例代数、磁盘摘要不符的诊断都丢掉；空列表清掉这个来源；不带版本的标未确认、不当成已修好；文件再变取消旧 pull、迟到的回复不进缓存。
3. **并发和锁**：两个会话同时改同一个文件；`std::sync::Mutex` 有没有跨 `.await` 持有；监视器回调和会话之间的引用环有没有放掉（关会话后 watcher 和实例订阅能释放）；计划 / 审查期间暂停、恢复后核对，不会漏同步或重复起实例。
