# 任务：第三期 - 实时提醒（Heads up）

类型：功能变更
依据：Claude Code 会在对话进行中，从旁看出一个潜在的问题，在输入框上方弹一条「Heads up · …」，下面三个选项：`1: Learn more`、`2: Knew this already`、`0: Dismiss`。canter 也要能在会话进行中实时给出一个潜在的意见。第三期做，第二期不做。
执行：派出
待用户：第三期开工时再和用户定怎么做（谁来看、什么时候看、花不花钱、怎么显示、三个选项各做什么）

## 用户原话

- 10-29 用户贴了 Claude Code 的截图：「✦ Heads up · 任务文件要求 tip 放哪一行、写哪些内容、开关叫什么都先停下来问主控，主 agent 没问，自己定了。」下面是「1: Learn more　2: Knew this already　0: Dismiss」。用户：「这个再派一个任务，表明是第三期的任务。实时给出一个潜在的意见。」

## 截图里看得到的（凭这一张图，没查 Claude Code 怎么实现）

- 一行：`✦ Heads up · <一句话的意见>`，说的是刚发生的事（这次是：被委派的 agent 没照任务文件先问，就自己拿了主意）。
- 三个选项：`1` 看详细、`2` 已经知道了、`0` 关掉。
- 意见是从旁看出来的，不是用户问的，也不打断模型正在做的事。
