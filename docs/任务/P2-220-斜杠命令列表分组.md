## 要做的

输入 `/`（以及接着打字筛选）时弹出的命令列表：

1. 分两组：先 `Commands`（内置命令），再 `Skills`（会话里的 skill），各一行组标题。筛选后哪组没有匹配项，那组连标题都不显示。
2. 两组各自对齐：命令名那一列按命令组里最长的名字定宽，不被长 skill 名撑宽；skill 组同理。
3. skill 行：名字、来源（`global` / `project`，未知来源写 `other`，暗色）、描述。描述压成一行，过长按现有办法截断加 `…`。不再每行写 `skill ·`。
4. 高度：组标题、条目和底部一行合起来最多 12 行；屏幕矮、现有可用行数更少时按更少的来。超出的上下滚动，选中项始终可见；滚动时，选中项所在组的标题始终显示在列表顶上。
5. 底部一行（暗色，照现有 `CHOOSE` 那种写法）：`↑↓ select · Tab complete · Enter run · <选中第几项>/<共几项>`。
6. 不变的：匹配规则（前缀匹配，内置命令占用同名）、条目顺序（命令在前、skill 在后）、↑↓ 跨组连续移动、Tab、Enter、Esc 的行为；`@` 文件列表和其它选择框不变。

屏幕上的文字都用英文。
