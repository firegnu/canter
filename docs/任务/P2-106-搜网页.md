## 现状和参考（10-30 主控查的）

- canter 现在只接 DeepSeek（Chat Completions），ChatGPT 登录没接（DESIGN 第 6、10 条），所以 OpenAI 自带的搜索用不上。
- **DeepSeek 搜索接口**（官方文档 https://api-docs.deepseek.com/guides/search ，10-17 开放）：
  - `POST https://api.deepseek.com/v1/tools/search`，`Authorization: Bearer <DeepSeek API key>`，`Content-Type: application/json`。
  - 请求：`query`（必填，1～128 个 Unicode 字符，不能全是空白）、`count`（1～50，默认 10）；还有 `ori_question`、`localization`、`need_content`，本件不用。查询里认 `site:`、`-site:`、`"..."`、`-`、`lang:`、`after:`、`before:`。
  - 返回 `results` 数组，每条有 `title`、`url`、`snippet`（100～200 字）、`summary`（600～800 字）、`date`（UTC，可能为 null）、`site_name`、`rerank_score`（0～3）、`authority`（0～4，-1 未知）等。
  - 价格：每 1000 次成功请求 0.75 美元；只有 HTTP 200 且 `results` 不空才收钱。限速：每账号每秒 100 次，超了回 429。
  - 错误码：400、401（key 不对）、402（余额不够）、408、413、429、500、504。文档说 408、429、5xx 可以等一会儿重试，402 要充值，其它 4xx 不改请求别重试。
- **别家怎么做的**（都是 canter 自己当工具，后面接搜索服务，跟聊天用哪个模型无关）：
  - omp（`can1357/oh-my-pi`）：`web_search` 工具接三十来家，DeepSeek 的在 `packages/coding-agent/src/web/search/providers/deepseek.ts`，文档 `docs/tools/web_search.md`。

  - 要看源码，克隆到 `/tmp` 下只读。只参考不搬的，在完成记录里写参考了哪里。
