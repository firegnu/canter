## 要做的

- **哪些能点**：
  - 回答里的网址：直接写出来的 `http://`、`https://` 网址，和 markdown 链接（现在显示成 `文字 (网址)`，文字和网址都能点，打开的都是网址）。网址末尾的标点（`.`、`,`、`)`、`，`、`。` 等）不算进去，括号配对的算。
  - 工具卡片标题里的文件路径：读文件、改文件、新建文件、改名后的新路径；网页抓取卡片里的网址。路径按会话的工作目录拼成绝对路径。
  - 其它协议（`file:`、`javascript:`、各种应用的 `xxx://`）不能点，也不加下划线。
  - 不做回答正文里提到的路径，不做 shell 输出里的网址和路径。
- **画法**：能点的部分加下划线，颜色不变。和 P2-44 搜索的下划线同时出现时怎么分开你定，写进完成记录。
- **怎么开**：鼠标按下、不动、松开，算一次单击。等约 0.4 秒（和 P2-45 的双击间隔一样）确认没有第二下，再打开；双击、三击照 P2-45 选词选行，不打开。从链接上开始拖照样是选字。单击链接以外的地方照 P2-45 的规矩（清选区）。
- **用什么开**（用 `std::process::Command`，不加依赖；不经过 shell，参数原样传）：
  - 网址：macOS `open <网址>`，Linux `xdg-open <网址>`。
  - 文件：macOS `open -t <路径>`（默认文本编辑器，不会运行它）；Linux `xdg-open`。目录：macOS `open <目录>`（Finder）。路径不存在时提示 `✗ No such file: <路径>`，不去开。
  - 起程序不等它结束，不卡界面；起不来时状态行红色提示原因。
- **SSH 下**（判断照 `copy.rs`）：不打开，改成把网址或绝对路径复制到剪贴板（走 P2-45 的复制），提示 `Link copied`。tmux 在本机时照常打开。
- **提示**：成功 `↗ Opened <网址或路径>` 约 2 秒，长了从中间截；失败红色约 5 秒。
- README 写哪些能点、怎么开、SSH 下复制。
