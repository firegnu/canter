## 主控当时记下的（11-02，未定）

现在 canter 的 MCP 只接工具（P2-12），连法支持本机起程序（stdio）和网址（Streamable HTTP），要登录的走 OAuth（P2-131），工具用到再加载（P2-162）。缺的三项：

1. **资源和提示词模板**：服务通过资源给的内容（文件、文档等）、提示词模板，canter 读不到。Codex、Claude Code 能读 MCP 资源。开工时要定：资源交给模型（给工具读）还是让用户在输入框里引用（Claude Code 打 `@`）；提示词模板要不要做成 `/` 命令；和 P2-162 按需加载怎么接。
2. **旧 SSE 连法**：MCP 标准已弃用，但还有一些老的远程服务只支持这种连法，不少 Claude Code 配置还在用。开工时要定：配置里怎么写（单独的类型，还是先试 Streamable HTTP、不行再退到 SSE）；OAuth 照 P2-131 一样接上。
3. **服务主动问用户（elicitation）**：服务在调用中途要用户填东西或确认，canter 现在不支持。开工时要定：问题怎么经协议到客户端（照现在的批准框，还是新的事件）；没人看着时（`canter exec`、长任务）怎么办；sampling、roots 这些客户端能力要不要一起查清支持到哪一步。
