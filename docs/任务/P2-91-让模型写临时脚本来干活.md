## 要做的

1. **每个会话一个固定的临时目录**：不管沙箱开关，会话打开就有一个只属于它的临时目录，作为模型 shell 的 `$TMPDIR`（沙箱开着时就是现在墙内可写的那个私有临时目录，范围不变，不开放整个 `/tmp`；沙箱关着时 shell 的 `$TMPDIR` 也指向它）。整个会话期间路径不变，改配置（P2-154 热加载、沙箱重建）也不换。路径要由会话决定、重开同一个会话时路径相同（比如按会话 ID 算出来），这样环境一段不因重开而变，不让 DeepSeek 的缓存白白凉一次（DESIGN 第 17 条）；目录只属于当前用户（0700）。
2. **什么时候删**：会话关掉或服务端停掉时删掉目录里的东西；重开会话时是一个空目录（同一个路径）。还在跑的后台命令照现在的规矩处理（`retired_tools` 那样等它们用完）。
3. **告诉模型**：在环境一段（打开会话时定下，会话中途不改）加一行。提示词原文用下面两句，按打开会话时沙箱开不开选一句，改动要先问主控（DESIGN 第 20 条，改提示词要用户点头）：

   沙箱开着：
   > `Scratch directory: <完整路径>. Put temporary files here (throwaway scripts, intermediate results, outputs that don't belong in the project) instead of the project or /tmp. It is private to this session, needs no approval, and is emptied when the session closes; copy anything worth keeping into the project or tell the user.`

   沙箱关着（只少了「needs no approval」）：
   > `Scratch directory: <完整路径>. Put temporary files here (throwaway scripts, intermediate results, outputs that don't belong in the project) instead of the project or /tmp. It is private to this session and is emptied when the session closes; copy anything worth keeping into the project or tell the user.`

   沙箱开着时 shell 说明里那句「a private temporary directory」改成指向 `$TMPDIR` 和这个目录，别的不动；沙箱关着时 shell 说明和现在一样。会话中途改配置开关沙箱，环境一段不跟着改（下次打开会话再按当时的开关选），批准按当时实际的沙箱开关算。
4. **write / edit 免批准（只在沙箱开着时）**：沙箱开着时，`write`、`edit` 写这个目录里的文件和 shell 一样不弹框，「全部允许」档也不拒；沙箱关着时照现有规矩（询问档弹框，「全部允许」不问）。只放行这一个目录，不放行 `/tmp` 别处，也不放行别的会话的目录；路径照 P2-118 的办法规范化（符号链接、`..`），不能借它写到目录外面。`read` 照现在的规矩。敏感路径、`fileRules`、计划模式和审查轮的限制照旧优先。
5. **判断不出来时**：目录建不起来（比如 `/tmp` 满了、权限不对）时，会话照常打开，环境一段不加那一行，write / edit 不放行，界面上用一行英文提示原因；不能因此把用户挡在会话外面。
6. **`/sandbox` 和 DESIGN**：`/sandbox` 列出的可写范围里显示这个目录的路径。DESIGN 写一节「会话临时目录（P2-91）」，写清上面 1～5 条和与 Claude Code、Codex 的对照。协议有变化的照第 8 条写明和 Codex 的不同。
