## 要做的

1. **按键**：普通输入框里按 Ctrl+G（Codex、Claude Code 都用这个键）打开外部编辑器。搜索框、批准框、提问框、弹框、会话列表开着时不起作用。
2. **用哪个编辑器**：先 `VISUAL`，再 `EDITOR`，按 shell 规则拆成程序和参数（比如 `code --wait`）；都没设时状态栏提示一句 `Set $VISUAL or $EDITOR to use an external editor`，草稿不动。
3. **写什么进去**：当前草稿写进一个只有用户能读写的临时文件（扩展名 `.md`，放在新建的私有临时目录里），`[Pasted …]` 标记换成粘贴的全文；`[Image …]` 标记照原样写进去。用完删掉临时文件和目录。
4. **交出终端**：退出全屏、原始模式、鼠标和键盘增强，让编辑器用整个终端；编辑器退出后恢复原样、整屏重画。这期间服务端来的事件不丢，回来后照常显示；读终端的线程不能和编辑器抢按键。
5. **放回来**：编辑器正常退出，文件内容（去掉末尾多出的一个换行）替换整个草稿，光标放到末尾；`[Image …]` 标记还在的，图片附件留着，删掉了的附件跟着去掉；粘贴的全文不再收成标记。编辑器退出码不是 0、启动失败或文件读不了时，草稿保持原样，状态栏写原因。内容清空了就是空草稿。
6. 加进 `?` 帮助弹框的输入框快捷键一节；DESIGN 第 19 条补一句定法，提交说明里写。
