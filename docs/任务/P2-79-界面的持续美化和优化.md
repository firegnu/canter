  - 状态行保留 `⏸ Waiting for approval` / `⏸ Waiting for your answer`，秒数改成这一次等了多久（从这个批准框、提问框出现算起）。

### 6. 重试每次一行、写法是程序内部的

- 现在：模型请求出错重试时，每次重试在对话里永久留一行：`Retrying in 3.9s (4/10): model request failed: Server (HTTP status: Some(500))`，10 次就 10 行。`Server`、`Some(500)` 是 Rust 的调试写法（`crates/canter-model/src/error.rs` 的 `retry_reason` 和 `ModelError` 的 Display）。最后失败时的报错也是同样写法：`model request failed: Server (HTTP status: Some(500)); retried 10 times`。
- 用户选：「留一行总结」。
  - 重试中：对话里只有一行，原地更新：`Server error (HTTP 500) · retrying in 4s (4/10)`。
  - 成功了：这一行变成一行暗色总结：`Retried 4 times after server error (HTTP 500)`（只重试一次写 `Retried once after …`）。
  - 最后还是失败：照现在显示报错，报错文字也改成人看的写法，比如 `Model request failed: server error (HTTP 500) after 10 retries`。
  - 各种错误的写法：限流 `rate limited (HTTP 429)`、服务端 `server error (HTTP 5xx)`、网络 `network error`、超时 `timed out`，其他类似；没有 HTTP 状态码就不写括号。
