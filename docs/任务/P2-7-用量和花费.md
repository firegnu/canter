## 要做的

- **单价**：
  - 程序自带 `deepseek-flash`、`deepseek-v4-pro` 的美元单价（每百万 token），分三档：缓存命中输入、未命中输入、输出（思考的 token 算输出）。照 DeepSeek 价格页填，代码里注明取价的日期和网址。DeepSeek 不收缓存写入费，不做这一档。
  - 配置加一项（名字你定，比如 `prices`），按模型名写三档单价，覆盖自带的，也给自己加的模型用。省略就只用自带的。写进服务端 README。
  - 没有单价的模型：照常记用量，花费记为未知，不当 0 算。
- **算钱**：每次模型请求（包括压缩请求）的花费 = 命中 × 命中价 + (输入 − 命中) × 未命中价 + 输出 × 输出价。由服务端算，客户端只显示。
- **记账**：从现在起每次请求的花费和实际用的模型随用量事件存盘，以后改单价不改已记的钱。以前的会话没记花费的，汇总时按当前单价补算；模型按那次请求之前最近一次 `session.updated` 里的模型算。协议的新字段都可选，旧会话、旧客户端照常读；和 Codex 不一样的地方写进 DESIGN 第 8 条。
- **`/usage`**：在对话里显示本会话的用量和花费：按模型分开列命中、未命中、输出的 token 数和花费，再列合计，再列上一轮的花费。没有单价的模型花费写 `unknown`。
- **`canter usage`**：命令行按天（本机时区）、按模型汇总所有会话，一行一个「日期 × 模型」，列命中、未命中、输出和花费，最后一行合计。数据经服务端取（服务端没在跑就像 `canter` 平时那样在后台起），不由命令行直接读状态目录。没有任何用量时输出一句说明。
- **状态栏**：第一行最后加本会话花费，比如：

  ```
   deepseek-flash · think high · Always ask · $0.12
   ~/canter (main) · ctx 42% 420k/1M · cache 92% (last 99%)
  ```

  还没有用量时不写；本会话有一次请求的花费未知时，写已知部分加 `+?`（比如 `$0.12+?`）。
- 金额写法（`/usage`、`canter usage`、状态栏一样）：不到 $0.01 但大于 0 的写 `<$0.01`，其余保留两位小数。
