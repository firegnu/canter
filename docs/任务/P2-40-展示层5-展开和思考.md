### 做了什么

- **Ctrl+O**（`app.rs`）：`App` 加 `details` 开关，Ctrl+O 切换，开 canter 时总是收起。按键在答案防误触的判断之后、批准框 / 提问框 / 选择框 / 列表之前处理，所以什么开着都切对话区，不会当成回答。`History` 记下这份是按哪个开关画的，开关一变像改宽度一样整段重画。状态行末尾加 `Details shown · Ctrl+O to fold`（空闲时单独一句，有别的字时前面加 ` · `）。
- **停在原来那一项**：`History` 和 `live_rows` 都记下每一部分（轮的提问、每一项、轮尾、提示行、排队的消息）从第几行开始。往上翻着时按 Ctrl+O，先找出视图最上面那行属于哪一部分，重画后把视图顶端放到这一部分的第一行。跟着最新输出时不动，照旧贴底。切换时清掉「上一帧看到的行」，免得把重画误当成新输出、亮出「New output below」。
- **展开的内容**（`cells.rs`）：`cells::item` 加 `details` 参数往下传。命令输出（MCP、网页抓取共用这张卡片）展开时全部显示、不写 `… (N lines…)`；历史里的 diff 不限行数，删除文件也显示删掉的内容；思考见下。批准框不受影响，照旧全显示。
- **思考**：进行中 `Thinking… <最新一行>`，放不下只留末尾、前面 `…`；结束后 `Thought: <第一行>`，后面还有内容加 `…`；有摘要用摘要，摘要开头 `**标题**` 去星号当这一行；展开时 `Thought` 一行，下面全文按 markdown 画、整体套「思考」样式（灰、斜体），每行前面灰色 `┊`。
- **批准框里超长的行**（`diff.rs`）：一对删加行里有一行超过 **1024 字节**就不按词比较，只铺整行底色（没底色时整行绿 / 红字）。历史和批准框共用这段，两边都生效。
- README 加「Ctrl+O 和思考」一节，diff 一节补上 1024 字节和 Ctrl+O。

### 拿主意的地方

- 长度上限 1024 字节，按字节数算，删行或加行有一行超就整对不比。
- 翻到某一项中间时按 Ctrl+O，顶端放到这一项的第一行（不保留在项里的偏移）：展开前后同一偏移对应的内容不一样，放第一行最不容易看错。新位置离底不够一屏时就照旧变成跟着最新输出。
- 删除文件展开时显示删掉的内容（P2-37 定的「只留标题」是收起时的样子）。
- 进行中的思考展开时标题写 `Thinking…`、下面已写出来的全文；结束后才是 `Thought`。
- 展开时思考全文用和收起时同一份：有摘要用摘要，没有用原文（两样都有的模型现在没有）。摘要多段之间、原文多段之间都按空一行（markdown 的分段）连起来。
- 「最新写出来的那一段」按最后一个非空行算；截出来的末尾去掉开头的空格。
- 展开时 markdown 里行内代码、代码块的颜色保留，再叠上灰和斜体；`┊` 只灰、不斜。
- 状态行在窄窗口里放不下时照旧被截掉末尾（60 列时「等批准」那行会截掉 `fold`），没另做处理。
