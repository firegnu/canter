## 要做的

照方案推荐做，要点：

- **Ctrl+O**：按一下，对话里所有收起的东西一起在原地展开：思考全文、命令输出全部、历史里的长 diff 全部；再按一下收起。已说完的部分和进行中的部分都算。
  - 展开着时状态行末尾写 `Details shown · Ctrl+O to fold`，空闲时也显示。
  - 往上翻着时按 Ctrl+O，画面停在原来最上面那一项上，不跳走；跟着最新输出时照旧贴着底。
  - 切换时已说完的部分像改窗口宽度一样整段重画。
  - 批准框、提问框开着时 Ctrl+O 照样切对话区；批准框本身照旧全显示。
  - 不记住：每次打开都是收起的。
  - 先查 Ctrl+O 现在有没有被别的按键用掉、终端里会不会被吃掉；有冲突，停下问。
- **思考**（灰色斜体，用 `theme.rs` 的「思考」）：
  - 进行中：一行 `Thinking… <最新写出来的那一段>`，截成一行，太长只留末尾、前面加 `…`，跟着思考往下走。
  - 结束后收起：一行 `Thought: <第一行>`，后面还有内容时以 `…` 结尾。有摘要时用摘要，摘要开头的 `**标题**` 去掉星号当这一行。
  - 展开：先一行 `Thought`，下面全文按 markdown 画，整体灰色斜体，每行左边一条灰色 `┊`。
  - 不做每块单独展开。
- **批准框里超长的行**（P2-37 记下的）：现在每帧给每对删加行做按词比较，极长的单行可能卡顿。超过一个长度的行不做按词比较，只铺整行底色；长度你定，写进 README 和完成记录。
