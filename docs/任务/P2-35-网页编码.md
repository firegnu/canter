## 要做的

- **用哪个编码**，照 WHATWG HTML 规范的先后：
  1. 开头有 BOM（UTF-8、UTF-16LE/BE）的，照 BOM；
  2. 否则 `Content-Type` 里的 `charset`；
  3. 否则（只限 HTML）在前 1024 字节里找 `<meta charset=…>` 或 `<meta http-equiv="Content-Type" content="…; charset=…">`。只做规范里「预扫」那种简单查找，不写完整的 HTML 解析；
  4. 都没有就照旧按 UTF-8。
- 编码名照 `encoding_rs` 的标签表认（`Encoding::for_label`，GB2312、GBK 都对到 GBK，latin-1 对到 windows-1252，这些都是规范规定的）。`text/*`、JSON 也照 `charset` 转。
- 转不了的字节换成 `�`，照常返回。
- 认不出的编码名：照旧按 UTF-8 解码，结果开头那行说明改成写明「认不出的编码 <名字>，按 UTF-8 解码」（英文，和现有说明同样的格式）。认出来、转好了的不再加说明。
- 转码在下载上限检查之后、`check_html` 和转换之前做；`check_html`、大栈线程、原文回退、截断都照旧，在转好的文字上做。
