## 要做成什么

模型用 read 读 PDF 时拿到文字（按页），过大时分页读；抽不出文字的（扫描件）如实说明。

## 待补

- 用哪个 Rust 库（成熟、活跃维护）、页数和大小上限、能看图的模型要不要给页面图，派之前问用户。

## 11-06 定的做法

- 主控查了 Codex `rust-v0.163.0`：没有读本地 PDF 的工具和库，提示词也没提 PDF，全靠模型自己跑 `pdftotext` 之类的命令，本机没装就读不出。Claude Code 是把 PDF 原样发给模型，DeepSeek、Kimi 不收，不能照搬。
- 主控列了三种（只靠提示词 / read 调本机 `pdftotext` / 编进 Rust PDF 库），推荐第 2 种，用户：「好的」。
  - read 遇到 PDF 时由 canter 调本机 poppler 的 `pdftotext`，按页给文字、过大分页读、扫描件说明没有文字；没装时给一句英文提示怎么装（`brew install poppler`）。
  - 照 read 的读文件权限走；`pdftotext` 有超时和输出上限，坏文件只让这次读取失败。
  - 模型看到的始终是「read 读 PDF 拿到按页文字」，以后要不依赖本机再把内部换成 Rust 库。
- 用户问「现在图片应该是支持的吧？」：canter 已能看图（P2-5、P2-130，按配置里模型的 `image` 标记），主控更正了「DeepSeek、Kimi 不收图片」的说法，建议加回页面图片，用户：「加进去吧」。
  - 某页抽不出文字（扫描件）且当前模型能看图时，用 poppler 的 `pdftoppm` 把那一页转成 PNG，走 read 现有的看图那条路（P2-130 的会话副本、大小上限和预算）交给模型。
  - 模型可以指定要某几页的图片（看图表、版面）。
  - 当前模型不能看图时只给文字，并说明那页没有文字。图片只在需要时给，不是每页都给。
