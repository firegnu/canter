## 要做成什么

GPT（`"api": "responses"`）每次请求结束（成功或失败）后，在服务端日志（`~/.canter/server.log`，沿用 P2-211 的写法）写一行英文，看了能回答：

1. 这是这个服务端进程里第几次 Responses 请求、什么时候发的、用了多久、发给哪个模型。
2. 这次的输入有几条，这次输入的开头是不是逐字节等于上一次请求的全部输入（不是的话从第几条开始不同）；工具列表和开头那条 developer 消息和上一次是不是一样。用短哈希或序号表示，不写内容。
3. 响应的 usage 里 `input_tokens`、`output_tokens`、`input_tokens_details.cached_tokens`，以及有没有缓存写入一类的字段：每个字段是「没有这个字段」还是给了哪个数，两者要分得开。
4. 输出条目的类型和顺序；每条在 `output_item.done` 和 `response.completed` 的 output 里各有没有 `encrypted_content`（以及 function_call 的 `encrypted_function_args`）；`response.completed` 的 output 是空、和流里一致、还是不一致。
5. 请求失败时是哪一类错误。

只写数字、序号、字段名、类型名、有无、短哈希（截短的哈希，从中推不出内容）。不写任何文字、参数、id、call_id、密文、令牌、错误原文。不改发出去的请求。
