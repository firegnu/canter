## 要做的

- **开头只在打开会话时定**：建会话、打开已有会话（包括服务端重启后接着聊）时读一次日期和 `AGENTS.md`，拼好开头；之后这个会话里的每次请求、手动压缩、自动压缩都用这一份，不再重读。会话中途改了 `AGENTS.md`、跨过 UTC 零点，都要到下次打开会话才用上。
- **打开已有会话**：从模型历史还原的开头和刚读到的不一样时（比如隔天打开、`AGENTS.md` 改过），照现在的做法在模型历史里记一条新的开头再用；一样就不记。
- **`AGENTS.md` 的警告**（读不了、不是 UTF-8、超过 64 KiB）：也只在打开会话时发，规则照旧。
- **守住前缀的测试**：用假模型记下每次请求发出的完整内容（消息、工具定义、模型名、思考和输出上限这些选项），检查除了压缩以后的第一次请求，每次都是上一次请求加上新内容：前面的部分一字不差。场景至少覆盖：连续几轮对话、一轮里调几次工具、插话、打断后再接着聊、等批准时拒绝、会话中途改 `AGENTS.md`、关掉再打开会话后接着聊（重开以后的第一次请求和重开前最后一次相比也算延续，除非开头确实变了）。
- `crates/canter-core/README.md` 里讲上下文的地方跟着改。
- **信息行显示命中率**：终端最底下的信息行末尾加 `cache 92% (last 99%)`：前一个是本会话累计的 `cachedInputTokens / inputTokens`，括号里是最近一次请求的；取整成整数百分比，样式和信息行其余部分一样（灰色）。还没有用量（新会话没调过模型）时不显示这一段；输入为 0 时不显示对应的数。窗口窄放不下时，照信息行现在的截断办法处理。数据直接用快照里的 `tokenUsage`，不改协议、服务端。
