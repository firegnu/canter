## 缓存命中的注意点（10-25，分解对应各件时写进要求）

- P2-2 切模型、思考档位：切模型后缓存必然全丢；思考开关影不影响命中，分解时查 DeepSeek 文档（只读文档，不调接口）。

- P2-9 btw：在当前上下文后面原样加问题，不另拼上下文。

- P2-12 MCP：工具列表顺序固定；会话中途 MCP 的工具变了怎么办，分解时定。

## 已定的验收（用户 10-24「照草稿」）

分解时照抄，不补不改：

- P2-1：输入 `/` 出命令列表，`/exit` 退出，`/new` 开新会话，`/resume` 出会话列表，`/compact` 压缩，`/mode` 换权限模式。
- P2-2：会话中途 `/think max`（或 DeepSeek 支持的最高档）、`/model <名字>` 后，下一次回答用新设置，状态栏看得到。
- P2-3：在有 `tdd` 技能的机器上，说「用 tdd 的方式改 X」，模型会去读那份 `SKILL.md` 再照做。
- P2-4：模型拿不准时弹出问题和选项，选了以后它接着干。
- P2-5：粘贴一张截图问「这是什么」，模型能描述图里的内容（DeepSeek 不收图片则不做）。
- P2-6～P2-18：分解时再和用户定。
