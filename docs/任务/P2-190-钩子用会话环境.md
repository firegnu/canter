## 要做的

- 钩子命令的环境和这个会话的模型命令用同一份：清掉服务端继承来的环境，换成会话的环境（客户端建会话或恢复时送来的那份），再由 canter 设 `CANTER_SESSION_ID`、`CANTER_PROJECT_DIR`。这两个以 canter 设的为准，客户端环境里有同名的也被盖掉。
- 工作目录照现在用会话目录。不给钩子加模型命令用的会话临时目录（`TMPDIR`）。
- 所有钩子事件都这样，包括 SessionStart、SessionEnd（含服务端停机时发的）、子 agent 相关的事件。子会话的钩子用哪份环境（子会话自己的还是父会话的），照子会话的模型命令用哪份来定，写进完成记录。
- 不按变量名写特例（不认 `CORRAL_` 之类的前缀），也不把服务端自己的环境混回去。
- 受限会话照现在不跑钩子。
- 环境照现在只在服务端内存里，不存盘、不进快照和事件、不写日志。
- 文档：DESIGN「钩子（P2-153）」一节写明钩子用会话环境，写上用户原话；`crates/canter-core/README.md` 或钩子相关说明有写环境的照改。
