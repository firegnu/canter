## 现在的样子

- 拖文件进终端，终端把路径当粘贴内容送进来。`crates/canter-tui/src/app.rs` 的 `handle_paste` 调 `crates/canter-tui/src/images.rs` 的 `pasted_path`：整段内容是一个路径（照 shell 的写法去掉引号和反斜杠转义）、指向 JPEG/PNG/GIF/WebP 文件，就 `attach_image` 挂成附件；否则当文字插进输入框。
- 一次拖几张时，几个路径用空格隔开（带空格的文件名会被终端加引号或反斜杠），`pasted_path` 遇到引号外的空白就返回 `None`，整段变成文字。
- 每拖一次挂一张，附件在输入框里累加；Ctrl+V 贴剪贴板图片另走一条路，这件不动。

## 要做的

- 粘贴进来的内容按 shell 的写法拆成几段（引号、反斜杠转义照现在的规则；不展开变量、`~`、通配符，不执行任何东西）。**每一段**都是认得的图片文件，就按原顺序全部挂成附件；**有一段不是**（或拆不开），整段照旧当文字插进输入框，一张都不挂。只有一段时和现在一样。
- 挂上的样子照现在单张：每张在光标处插一个 `[Image #N 名字]` 标记，几张之间用一个空格隔开，编号照现在的规则接着排。
- 多次拖：每次照上面处理，插在当时的光标处，附件接着累加，不清掉之前的。
- 当前模型不收图时，照现在单张的提示（`… does not accept images; switch with /model …`），一次拖几张也只提示一次，一张都不挂。
