## 要做的

### 1. 程序名蓝色加粗

- 命令卡片标题（`Run` / `Running` / `Ran` 后面的命令）里，每一段命令开头的程序名用蓝色加粗：整条命令的第一个词，以及 `;`、`|`、`&&`、`||`、`&` 后面的第一个词。
- 程序名前面有 `VAR=value` 这类环境变量赋值、`sudo`、`env`、`time` 这类前缀的，怎么算由你按常见写法定，写进完成记录；不要为此做完整的 shell 解析。
- 参数、引号里的字、操作符、重定向的颜色照现在（`highlight::bash` 给的）。
- 多行命令每一行照同样的规则；命令被截成 `… N more lines` 时不受影响。
- 用户自己用 `!` 跑的命令卡片同样处理。
- `NO_COLOR` 下：程序名只加粗。

### 2. 命令输出变灰

- 现在成功命令的输出用的是终端的淡化效果（`dim`），用户的终端里看不出和命令有区别。改成明确的灰色前景（和思考行 `✻ Thought for 2s` 用的灰色同一档，或主题里现有的同类灰色），让输出在深色、浅色背景下都明显比命令淡。
- 管到的范围：`└` 下面的命令输出，包括成功的、还在跑的、Ctrl+O 展开后成功的。
- 失败命令的输出照现在保持正常颜色（要看报错）。
- `+ N lines (Ctrl+O to expand)`、`… N lines above (Ctrl+O to expand)`、`└` 这些提示照现在。
- `NO_COLOR` 下照现在。
