## 要做的

- **拖动选中**：在对话区按住左键拖，选中的字反白，可以跨行。
  - 拖到对话区最上沿或最下沿时，对话跟着滚，选中范围跟着扩大，能选到当前一屏以外。
  - 选中的位置钉在对话内容上，不钉在屏幕格子上：滚轮翻页、进行中的部分长出新内容时，反白跟着字走。窗口宽度变了或 Ctrl+O 展开收起导致重新折行时，选中清掉就行。
  - 双击选一个词，三击选一整行（显示的那一行）。
  - 点一下别处、按 Esc、开始打字时清掉反白。
  - 只做对话区；输入框、状态栏、批准框里不拖选，照现在。
- **松开就复制**：松开时选中非空就写进剪贴板，状态行提示 `✓ Copied N lines · M chars` 约 2 秒后恢复；失败时红色 `✗ Copy failed: <原因>`。和状态行别的内容同时出现时怎么排你定，写进完成记录。
- **复制出来的文字**：只要内容，不要装饰。
  - 去掉卡片和项目前面的标记（`●`、`◇`、`✗`、`›` 等）、输出前的 `│`、左边的缩进、diff 的行号和 `+`/`-`、右侧的状态（`running`、`exit 0` 等）、思考的 `┊`。
  - 因为窗口窄自动折行的，接回一行；原文本来的换行保留。
  - 只选了一行中的一段，就只要那一段。
  - 哪些格子算装饰、怎么标，你定，写进完成记录。
- **`/copy`**：复制最后一条回答的原文（markdown）；`/copy N` 复制最后一条回答里第 N 个代码块的代码本身（不带围栏）。成功的提示同上；没有回答时 `Nothing to copy`；N 超出时提示一共有几个代码块。命令列表和 `/help` 里加上。
- **写剪贴板**：加 `arboard`（用户已同意加这个依赖，版本你选当前稳定版，写进完成记录）写本机剪贴板；在 tmux 或 SSH 里另外用 OSC 52 发给终端，tmux 里照 Codex 的办法包一层。写剪贴板不能卡住界面（Codex 放在单独的线程里）。
- README 里写怎么选、怎么复制、`/copy`，以及在 tmux、SSH 里靠终端支持 OSC 52。
