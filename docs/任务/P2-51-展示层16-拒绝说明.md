## 要做的

协议（字段名照写，都是可选、旧的一方照兼容规则跳过）：

- `ApprovalDecision` 加 `DeclineWithFeedback`（JSON `declineWithFeedback`）。
- `RequestResolveParams` 加可选 `feedback: Option<String>`。只和 `declineWithFeedback` 一起用：`declineWithFeedback` 没带 `feedback`、或去掉首尾空白后为空，报 `invalid_decision`；别的 decision 带了 `feedback`，也报 `invalid_decision`。这个请求的 `availableDecisions` 里没有 `declineWithFeedback` 时同样拒绝。
- `ApprovalResolution::Answered` 加可选 `feedback`，跟着 `request.resolved` 事件存盘；旧的事件没有这个字段，照旧能读。
- 导出的 JSON Schema、TypeScript 跟着更新。

服务端（工具层、核心）：

- 需要批准的工具，`availableDecisions` 是 `accept`、`acceptForSession`、`decline`、`declineWithFeedback`、`cancel`。
- `declineWithFeedback` 和 `decline` 一样：不执行、这一轮不停、工具卡片是 `declined`。区别只在交给模型的工具结果：`Tool call declined. The user says: <这句话>`（这句话照原样，不翻译、不截断）。
