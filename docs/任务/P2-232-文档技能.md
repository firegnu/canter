## 要做的

1. **三个技能**：`docx`、`pptx`、`xlsx`，各一个 `SKILL.md`，英文写。每个都要写清：
   - 什么时候用（说明写清文件类型和要做的事，让模型能判断该不该加载）。
   - 读：怎么把内容、表格、批注、备注、公式等读出来。
   - 生成：怎么从零做一份格式像样的文件。
   - 修改：怎么改已有的文件、尽量不弄坏原来的格式（比如直接改 zip 里的 XML，或用对应的库）。
   - 先看本机有什么工具（pandoc、textutil、Python 及库、node、uv、LibreOffice 等），按有的选；都没有时怎么办。
   - 需要装库时，优先用不污染全局环境的办法（比如 `uv run --with <库>`），要往全局装东西先告诉用户。
   - 由模型按需自己写脚本做解析、分析、生成，技能里给关键的结构说明、命令和常见坑，不带一大套现成脚本（个别很短的示例片段可以写在说明里）。
