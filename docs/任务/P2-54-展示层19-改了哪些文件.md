## 要做的

每轮末尾：

- 一轮里有改成功的改文件项目（`Item::FileChange`，状态 `completed`）时，这一轮末尾、`Worked for` / `Turn interrupted` / `Turn failed` 那一行上面加一段：

  ```
  ● Changed 3 files  +40 −12
      src/app.rs      +30 −8
      src/input.rs     +8 −4
      README.md        +2
  ─ Worked for 1m 12s ─
  ```

  - 第一行是文件数和加删总行数（`file` / `files` 单复数）；下面每个文件一行，路径照改文件卡片的写法，行数对齐成一栏，没有删的不写 `−0`。
  - 新建的文件写 `new`，删除的写 `deleted`，改名的照卡片写法；同一个文件这一轮改了几次合成一行、行数加总；顺序照第一次改它的先后。
  - 多于 8 个文件只列前 8 个，最后一行 `… and N more`。
  - 只算改文件的工具（失败、被拒的不算）；shell 命令改的不算。被打断、出错的轮改了文件也列。
  - 从快照里的项目算，不存盘、不改协议；重开会话照样显示。颜色照现有的：`+` 绿、`−` 红，别的暗色。这一轮还没结束时不画。
- 正在进行的轮不画；Ctrl+O 展开、收起不影响这一段。

`/diff`：

- 新命令 `/diff`（说明 `Show uncommitted git changes`），不带参数。在会话工作目录里跑 git：暂存的 diff、未暂存的 diff、未跟踪的文件列表。git 的调用和参数、安全设置（`filter_overrides`、`--no-ext-diff`、`--no-textconv` 等）、输出上限和截断都沿用 `review.rs` 那套，抽出来共用，不另写一套。
- 显示在和 `/context` 同一种弹框里，标题 `Diff`，分节：`Staged`、`Unstaged`、`Untracked`（只列文件名）；没有内容的节不写。diff 照对话里的画法（`diff.rs`：行号、底色、语法色）。截断时写明 `Truncated at … ; run git diff for the rest`。
- 不在 git 仓库里时弹框写 `Not a git repository`；没有改动时写 `No uncommitted changes`；git 出错时写出错原因（照 `/review` 的写法）。
- 跑 git 时界面不卡住（照 `/review`、`/files` 现在的做法）。
- 帮助弹框的 `Commands` 一节、命令列表跟着有 `/diff`。README 补上每轮末尾那一段和 `/diff`。
