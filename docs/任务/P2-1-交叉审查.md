## 重点看

1. **权限会不会被意外换掉**：`/mode` 的解析（大小写、多余空格、多余参数、前缀如 `/mode allow`）只在三个全名上换模式；三选一默认选在当前模式上；三选一开着时批准框弹出、关掉、再按键的各种顺序；按键排队时（画面还没换）会不会把为别的画面按的 Enter、方向键算到三选一或命令列表上。
2. **会不会意外花钱或丢上下文**：只打 `/`、`/c`、`/co` 等按 Enter 不压缩；`/compact` 在回答中途、在批准框等待时被拒绝的处理；粘贴一大段以 `/` 开头的文字时会不会被当成命令执行。
3. **换会话**：`/new`、`/resume` 换过去以后，旧会话的事件不再画到新会话上，批准框不串会话（旧会话的批准请求不会在新会话的画面上被回答）；换会话中途服务端断线、重连时接的是哪个会话；退出时打印的 `To resume` 是当时所在的会话。
4. **分辨命令和普通消息**：`/tmp/a.txt 看看这个` 这类照常发出去；不认识的命令不发给模型、草稿留着。
5. **验收**：输入 `/` 出命令列表，`/exit` 退出，`/new` 开新会话，`/resume` 出会话列表，`/compact` 压缩，`/mode` 换权限模式。
