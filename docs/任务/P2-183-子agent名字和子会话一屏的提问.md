## 要做的

### 1. 子 agent 的名字由模型给

- `spawn_agent` 加一个必填参数 `name`：说明（英文）写清是 3～5 个英文词的短名字，说清这个子 agent 干什么，给用户在列表和卡片里看（照 Claude Code 子 agent 工具的短描述参数）。参数位置和其余说明照现有写法。
- 服务端兜底：`name` 缺了、去掉首尾空白后为空、或超过 40 个字符时，从任务第一行取前 5 个词（超过 40 个字符截断加 `…`）当名字；不因为名字拒绝开子 agent。
- 同一个主会话的直接子 agent 里重名时，后开的加 ` 2`、` 3`……
- 名字存进子会话现有的名字字段，列表、卡片、批准框来源行、统计、钩子里显示的都是它。已有的旧子会话名字不改。
- 工具定义变了，发给模型的请求内容跟着变：相关的请求夹具一起更新，原有断言不放宽。

### 2. 子会话一屏提示主会话在等你

- 在子会话一屏时，主会话有等你回答的 `ask_user` 提问或等你批准的计划，在顶上固定两行下面加一行黄色 `Main session is waiting for you · /agents to go back`。
- 点这一行直接回主会话（等于 `/agents` 选 `← Main session`）。
- 提问答完、计划批准或拒绝、被撤回后，这一行消失。
- 批准照 P2-179 照旧弹出，不加这一行。
- 用 P2-179 子会话一屏已经订阅的主会话快照和事件判断，不加新的服务端接口；如果确实要改协议，停下来问。
