### 规则

- **进出全屏**：打开时进终端的备用屏幕（alternate screen），接管鼠标；退出（含出错、panic）时都恢复原来的屏幕和鼠标设置，再打印现在就有的 `To resume: canter --resume <id>`。会话列表（`canter --resume` 不带 id 时）也在全屏里显示。
- **对话区**：内容不满一屏时从顶上往下排；超过一屏时默认跟着最新输出，最底下一行紧挨着状态行。屏幕最上面不放标题栏。
- **往上翻**：鼠标滚轮每格翻几行，PgUp/PgDn 翻一页。翻上去以后有新输出不跳回底部，在状态行上方显示 `↓ New output below · scroll down or press PgDn`；滚回最底下，或者发出一句话，恢复跟着最新输出。
- **批准框**：照现在的样子换掉输入框的位置。批准框开着时 PgUp/PgDn 照旧翻批准框，鼠标滚轮翻对话。
- **改窗口大小**：整段对话按新宽度重新折行。
- **样式不变**：颜色、`›`、卡片、diff、命令输出、思考折叠、状态行、信息行的文字和样子都沿用现在的，只改摆放。界面文字用英文。
- **不变的行为**：P1-14 的批准框和输入框保护期、帧号判断（按键按发生时屏幕上那一帧处理），Esc 打断，Ctrl+C、Ctrl+D，重连，两个终端同看一个会话，都照旧。
- 现在「已经说完的行写进终端滚动区」那套（`terminal.rs` 的 `InlineTerminal`、往滚动区写行的记账）不再需要的，删掉，不留旧模式的开关。
- 现有测试里比对画面的期望（`tests/expected/replay.txt`、`tests/tui.rs` 里的画面断言）照新布局改；测的行为不变，不删测试、不放宽断言。
