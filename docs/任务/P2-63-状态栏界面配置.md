## 要做的

- **`/statusline` 命令**：打开上面那样的选择框。
  - 可选的项：model、thinking、permission、cost、directory、branch、context、cache、tps、version、session（会话名，没名字时不显示）。每项在状态栏里的写法、颜色照默认状态栏现在的（tps、version、session 现在默认不显示，写法照 P2-60 README 里的示例脚本：`32.5 tok/s`、版本同欢迎头）。拿不到值的项在状态栏里不出现，和现在一样。
  - 一条「line 2」分行线，和别的项一样能移：线上面的在第一行，下面的在第二行；放到最后就只有第一行，第二行空着。
  - 空格开关当前项，←/→ 把当前项（或分行线）往前、往后挪一位，↑/↓ 选项；下面实时预览两行；Enter 保存并关掉，Esc 不保存关掉。
  - 默认（从没存过）是现在的两行：第一行 model、thinking、permission、cost，第二行 directory、branch、context、cache，其余不勾。什么都没改时，状态栏和现在一模一样（现有期望画面不应因此改变）。
- **存盘**：存 `~/.canter/tui.json`（设了 `CANTER_HOME` 时放那个目录），权限 0600，写的时候先写临时文件再改名，不留半截文件。内容只有状态栏的项和顺序（含分行线的位置）。读的时候文件不在、读不了、格式不对、里面有不认识的项，都不出错：不认识的项跳过，整体读不了就照默认，状态行提示一次读不了。不写 `config.json`。
- **生效**：Enter 保存后本终端的状态栏立刻换；别的开着的终端下次打开才换，不做文件监听。
- **和脚本**：`config.json` 配了 `statusLine` 脚本时，选择框最上面多一行开关 `[x] Use statusLine script`（照 Codex 选择框顶上「Use theme colors」那种，不参与排序，和下面的项之间隔一条线），空格开关：
  - 勾着（默认）：状态栏照旧显示脚本输出，预览也写明用的是脚本；
  - 取消勾选并保存：状态栏改用下面选的项，开关状态记进 `tui.json`；再勾上并保存就回到脚本。不改 `config.json`。
  - 没配脚本时不出现这一行，`tui.json` 里记着的开关状态不影响什么。
- **矮窗口**（10-27 用户：选择框约 19 行，加上输入框和底部两行要约 25 行，常见窗口和分屏放不下；选了主控推荐）：选择框放不下时，先让上面的对话区让出地方；还放不下，项目列表（含 `Use statusLine script` 开关下面的那些项和分行线）只显示放得下的几行，跟着光标滚，光标所在项总在可见范围里，上面还有没显示的写一行 `   ↑ N more`，下面有写 `   ↓ N more`；标题、按键说明和预览一直留着；列表剩不到 3 行时把预览（含 `Preview` 那行）收起。窗口够高时和上面的样子一模一样。
- **窄窗口和 Shift+Tab**：每行放不下照现在的规则截；permission 勾着且在第一行时照旧要求它完整可见；permission 没勾或挪到第二行时，按 Shift+Tab 照配了脚本时那样，上面的状态行短暂提示 `Mode: 新模式`。
- README 加 `/statusline` 一节，「定制状态栏」里写明 `/statusline` 里的脚本开关。
