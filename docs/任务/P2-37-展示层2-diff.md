## 要做的

照方案第 2 项「推荐」做，要点：

- **统一 diff**，一列行号，宽度按这份 diff 里最大行号的位数；删行用旧行号，加行和上下文用新行号。不再显示 `@@` 行，块和块之间一行灰色 `⋮`。
- **底色**：真彩或 256 色、且知道深浅时，加行、删行整行铺底色（铺到行尾），文字默认色，`+` / `-` 号绿 / 红。16 色或不知道深浅时不铺底，整行绿 / 红字（现在的样子）。底色用 `theme.rs` 里已定的用途。
- **256 色就近取**：P2-36 审查发现深色底的加行色 `#213A2B` 就近取成了灰 236，绿色几乎没了。换一种取法，让 256 色下加行看得出绿、删行看得出红；`theme.rs` 里 `colorfgbg` 的注释顺手改对（0–6 不是「黑到浅灰」，7 才是浅灰）。
- **行内改动**：连着的一段删行和加行，行数一样时一一配对，每对按词比较，改动的词用「改动的词」底色，16 色下反色。用 similar 的 `inline` 功能（开 feature，版本不变）。一对里相同的部分不到一半就不标；行数不一样不配对、不标。
- **收起**：历史里改文件每个文件最多 12 行，新建文件最多 6 行，删除文件只留标题；多的写一行 `… N more lines`（先不带 `· Ctrl+O`，第 5 件 P2-40 接上展开）。
- **批准框**：和历史共用一套画法，但照旧全显示、可以翻；照旧先过 `visible()`，新画法不能绕过它。
- **长行**：照旧折行，折出来的行对齐到行号后面的文字。
- README 里讲 diff 的地方照新画法改。
