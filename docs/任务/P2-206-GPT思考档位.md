1. **档位按模型来**：配置里每个模型可以写它支持哪些档位和默认档位（字段名你定，写进 DESIGN 和服务端 README 的配置例子）。没写的模型照现在的规则（none/low/high/max、默认 high），所以 DeepSeek、Kimi、opencode go 这些不用改配置、行为不变。

4. **换模型时**：切到一个不支持当前档位的模型（比如 DeepSeek 的 none 切到 GPT，或 GPT 的 xhigh 切到 DeepSeek），改用目标模型的默认档位，并在界面上告诉用户换成了什么。
5. **服务端把关**：任何客户端（TUI、`canter exec`、协议请求）设成当前模型不支持的档位，服务端拒绝并给出能看懂的英文提示，不悄悄改成别的。
