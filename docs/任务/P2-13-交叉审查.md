## 重点看

1. **权限**：`web_fetch` 是否一律过闸门（一直问 / 问执行弹框，全都允许直接跑），参数错误等路径有没有绕过；「本会话都允许」的 `host:port` 判断准不准（大小写、末尾的点、IP 的不同写法、国际化域名、默认端口和显式端口、http 和 https）；有没有办法用一个已放行的域名去抓别的域名（跳转、`Location` 写法、相对地址）；审查轮一律拒绝且不弹框。

4. **结果**：截断照现有上限；非 UTF-8 编码的页面、`charset` 声明、压缩响应怎么处理；错误作为工具错误回给模型、这一轮继续。
